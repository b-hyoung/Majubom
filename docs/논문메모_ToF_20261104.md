# 논문 메모 — 새 침상(Bed C) ToF 재실·자세 판정 개선 (2026-11-04)

논문 방법·결과·한계 절에 옮겨 쓰기 위한 기록이다. 수치는 모두 이날 Pi에서 실제 녹화·실시간 프레임으로 계산했다.
"정확도가 좋아졌다"는 사용자가 대시보드를 보며 확인한 정성 관찰이며, 개선 후 정확도를 정량으로 다시 잰 것은 아니다(아래 '남은 일').

## 1. 설치 조건

- 센서: VL53L5CX(8×8 거리, 시야 45°×45°) 2개. 삼각대에 발 쪽(tof1)과 머리 쪽(tof2)에 하나씩 세워 침대를 길이 방향으로 마주 보게 설치했다. 센서마다 ESP32-S3 하나가 붙어 있고, 프레임은 Wi-Fi로 Pi에 들어온다. 센서당 약 10~11Hz.
- 침상: 병원 침대, 누울 수 있는 면은 2.0m×0.8m, 매트리스 윗면은 바닥에서 0.70m, 두 센서 사이는 약 2.05m(사용자 실측).
- 센서 자세(역산): 빈 침대 기준 거리 64칸을 '매트리스 평면 + 핀홀 광선' 모델에 최소제곱으로 맞췄다(평균 오차 5~7cm).
  - 결과: 두 센서 모두 바닥에서 약 1.25m, 아래로 약 47~48°.
  - 각 센서가 보는 범위는 침대 끝에서 0.20~1.02m다. 두 시야가 침대 중앙(1.0m)에서 겨우 맞닿는다.
  - → **침대 중앙이 두 센서 모두에게 시야의 맨 끝 줄**이다.

## 2. 문제 1 — 유효한 측정이 '측정 실패'로 버려짐

- 현상: 원시값 화면에서 침대 안쪽 칸들이 한두 프레임씩 '—'(-1)로 깜빡였다.
- 원인: 펌웨어가 센서 상태 코드 5(완전 유효)인 칸만 거리로 보내고, 나머지는 모두 -1로 보냈다.
- 실측(빈 침대 15초, 센서당 158프레임):
  - 무효 처리된 칸의 상태 코드: tof1은 255(반사 없음) 161, 9가 114, 10이 12. tof2는 255가 1,064, 9가 73, 10이 120.
  - 상태 9의 원래 거리는 이웃 칸과 같은 값이었다(예: 470~490mm 줄에서 470~490mm). ST 문서에서도 상태 9는 유효 거리다.
  - 끊김 길이는 대부분 1프레임이었다(tof1 104회, tof2 112회). 2~3프레임 끊김은 tof1 13회, tof2 36회였다.
- 처리 (서버 `clean_distances`):
  - 상태 5와 9는 유효로 보고, 펌웨어가 함께 보내는 원래 거리를 쓴다.
  - 그래도 빈 칸은 직전 유효값으로 최대 3프레임(약 0.3초) 채운다.
  - 펌웨어는 바꾸지 않았다. DB 원시 기록과 학습용 스트림은 원본 그대로 두었다.
- 결과: 빈 침대 15초 동안 침대 안쪽 칸의 '—' 비율이 0%가 됐다. 남은 '—'는 침대 밖 구석(상태 255)뿐이다.

## 3. 문제 2 — 재실 기준이 중앙 자세를 놓침

- 현상: 침대 위에 앉아 있거나 중앙 가장자리에 걸터앉아도 '이탈'로 떴다.
- 원인: 재실 기준이 너무 높았다. 예전 기준은 '한 센서에서 빈 침대 기준보다 150mm 넘게 가까운 칸이 8개 이상'이었다. 이 값은 예전 4×4 설치의 값을 비례로 늘린 것으로, 실측으로 검증한 적이 없었다.
- 평가 방법:
  - 운영 모델을 학습한 녹화(S01 재촬영·S02·S05, 자세·위치별 약 30초)에 서버와 같은 계산을 적용했다(칸마다 최근 3프레임 중앙값).
  - 빈 침대 기준은 각 녹화와 가장 가까운 시각의 빈 침대 녹화에서 칸별 중앙값으로 만들었다.
  - 아래 표의 수치는 '재실 조건을 넘은 프레임의 비율'이다.

| 녹화 | 예전 기준 (한 센서 150mm·8칸) | 바꾼 기준 (두 센서 합 100mm·3칸) |
|---|---|---|
| 중앙 걸터앉음 S01 / S05 | 0% / 0% | 100% / 100% |
| 중앙 앉음 S01 / S05 / S02 | 100% / 1% / 0% | 100% / 100% / 78% |
| 바로 누움 가운데 S02 | 16% | 100% |
| 빈 침대 (학습 9세션 + 실시간 20초) | 0% | 0% |
| 중앙 걸터앉음 S02 | 0% | 0% |

- 비교한 조합: 거리 차이 80·100·120·150mm × 두 센서 합 2·3·4·6·8칸. 빈 침대 오탐은 모든 조합에서 0%였다. 그중 중앙 자세를 높게 잡으면서 기준을 지나치게 낮추지 않는 조합(100mm·3칸)을 골랐다.
- 참고로 같은 150mm에서 칸 수만 '두 센서 합 8칸'으로 바꾸면 중앙 걸터앉음 S01 48%·S05 30%, S02 바로 누움 21%였다. 즉 '한 센서'를 '두 센서 합'으로 바꾸는 것만으로도 중앙 자세가 일부 잡힌다(중앙에서는 몸이 두 센서에 나뉘어 걸리기 때문).
- 바꾼 기준(사용자 결정):
  - 재실 진입: 두 센서 합으로 100mm 넘게 가까운 칸이 3개 이상.
  - 재실 유지: 같은 조건에서 2개 이상.
  - 몸 위치 계산(가장자리 쏠림)은 예전 150mm를 그대로 썼다.
- S02 수치 주의: S02 녹화는 같은 시각의 빈 침대 녹화가 없어서, 2.5~3시간 떨어진 빈 침대 녹화를 기준으로 썼다. 그래서 S02 수치는 불확실하다.
- 중앙 걸터앉음의 한계: 몸이 매트리스 밖에 있어서 두 센서 모두 가장 먼 한 줄에만 2~4칸 걸린다. 체구가 작은 S02는 어떤 기준으로도 0칸이었다. **기준값으로는 해결이 안 되고, 센서 배치가 원인이다**(5절).

## 4. 문제 3 — 화면 자세 깜빡임

- 현상: 자세 판정은 프레임마다 나온다. 사람이 조금만 움직여도 화면이 '이탈'과 '걸터앉음' 사이를 오갔다.
- 처리: 화면에 보이는 자세만 바꿨다. 최근 2초 판정 중 70% 이상을 차지한 자세가 있을 때만 화면을 바꾸고, 아니면 이전 표시를 유지한다. 예전에는 새 자세가 0.5초만 이어져도 바뀌었다.
- 판정·알림에 쓰는 프레임 단위 자세는 그대로다.

## 5. 센서 배치 시뮬레이션 (중앙 가장자리 걸터앉음)

1절에서 역산한 모델로 계산했다. 걸터앉은 상체는 침대 폭 가장자리 근처(가로 0.15~0.45m), 길이 방향 0.85~1.15m, 매트리스 위 0~0.75m 높이의 상자로 두었다. 이 상자에 가려 빈 침대보다 150mm 넘게 가까워지는 칸 수를 센서 하나 기준으로 셌다.

| 높이(바닥에서) | 하향 각도 | 중앙 걸터앉음 칸 | 센서 앞 사각 | 반대쪽 끝까지 보이는 거리 |
|---|---|---|---|---|
| 1.25m (현재) | 48° | 2칸 | 0.20m | 1.0m |
| 1.25m | 35° | 9칸 | 0.36m | 1.98m |
| 1.4m | 40° | 10칸 | 0.38m | 1.87m |
| 1.6m | 45° | 12칸 | 0.40m | 1.88m |
| 1.8m | 45° | 14칸 | 0.50m | 1.81m |

- 현재 설치에서 계산한 값은 2칸이고, 실제 녹화는 2~4칸이었다. 모델이 현실과 맞는다.
- 높이를 1.6m로 올리고 45°로 두면, 두 센서 시야가 침대 대부분에서 겹친다. 양쪽 끝 약 0.12m만 사각으로 남는다.

## 6. 자세 모델 관련 관찰

- 운영 모델: 원시 거리 128개(실패 칸은 -1)를 입력으로 쓰는 Random Forest(트리 200그루). S01 재촬영·S02·S05 실측 8,106쌍으로 학습했다(노트북에서 학습).
  - 사람 단위 교차검증: 정확도 61.15%, macro-F1 0.5906. S01 42.3%, S02 70.1%, S05 71.1%.
  - 같은 비교에서 CNN 특징 + XGBoost(합성 데이터 50%)는 46.84%였다.
  - Pi CPU에서 한 번 판정에 약 30ms.
- 실패 사례: 같은 RF에 걸터앉음을 직접 녹화한 2,271쌍을 더해 다시 학습한 모델을 써 봤다.
  - 노트북 시험에서는 걸터앉음 476쌍을 모두 맞혔다. 다만 같은 사람·같은 녹화를 시간으로 나눈 시험이었다.
  - 실제 운영에서는 이불·베개가 있는 빈 침대를 걸터앉음으로 잘못 봤다(확신 0.95~1.0). 그래서 바로 되돌렸다.
  - 교훈: 같은 녹화를 시간으로 나눈 시험은 성능을 크게 부풀린다. 헷갈리는 반대 사례(지금 침구 상태의 빈 침대)를 학습에 넣어야 한다.
- 빈 침대 게이트: 사람 칸이 0이면 모델 출력을 무시하고 '빈 침대'로 둔다. 위 오판이 화면에 나오지 않은 것은 이 게이트 덕분이다. 이 게이트와 재실 기준은 같은 '사람 칸' 계산을 쓰므로, 3절의 기준 변경이 둘 모두에 적용됐다.

## 7. 한계와 남은 일

- 개선 후 정확도를 정량으로 다시 재지 않았다. 녹화를 새 파이프라인(칸 정리 → 재실 → 자세 → 화면 다수결)에 다시 흘려서 프레임 단위와 화면 표시 단위의 정확도를 재야 한다.
- 2절의 칸 정리는 운영 서버에만 들어가 있다. 학습 데이터는 원본(상태 5만 유효)이다. 학습에도 같은 정리를 넣어 학습과 운영 입력을 맞춰야 한다.
- 재실 기준을 낮춰서, 이불·베개가 10cm 이상 옮겨지면 사람이 없어도 재실로 남을 수 있다. 모델 기반 빈 침대 기준 자동 갱신(빈 침대 판정이 1분 동안 80% 이상일 때)이 이를 일부 보완한다.
- 참가자 세 명(왜소한 체형 남성 2명, 큰 체격 1명)으로만 확인했다.
- 센서 높이·각도 변경(5절)은 계산만 했다. 바꾸면 기존 녹화와 모델이 새 시야와 맞지 않으므로 다시 녹화하고 다시 학습해야 한다.
