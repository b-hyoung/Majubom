# 대시보드 캡처 (2026-10-11, 캡스톤디자인 경진대회 초록용)

라즈베리파이에서 실제 서버(:5001 간호사 대시보드, :5012 로우데이터 대시보드)를 헤드리스 Chromium으로 열어 찍었다.
ToF 두 센서와 mmWave는 실제로 수신 중이었고, 캡처 시점에 침대는 비어 있었고 방에 사람이 없었다.

## 캡처로 채울 수 없는 칸
- 센서 2종 사진, 수집·분석 디바이스 사진, 테스트베드 구축, 통합 테스트: 실물 사진이 필요하다.
- 낙상위험 알림 **모바일 앱**: 구현되지 않았다. 현재 알림은 웹 대시보드 화면 표시(팝업)뿐이다.

## 주의
- mmWave 포인트 클라우드와 보행 지표 값이 비어 있는 것은 캡처 순간 방에 사람이 없었기 때문이다.
- 낙상 팝업은 시뮬레이션 데이터다. 초록에 쓸 때 "시뮬레이션 화면"임을 밝힌다.
