분석과 AI가 맡는 일

01

자세 분류 · 침상 위험

ToF 거리 배열 → Random Forest 자세 분류 → 몸 중심과 자세 규칙. 선택적 LSTM-AE는 별도의 움직임 이상 참고값입니다.

02

보행 변화 · 통합 위험

mmWave 보행 지표를 개인 기준과 비교하는 Z-score 통계. 유효한 센서 판정과 데이터 품질을 확인해 위험 수준을 구성합니다.

03

근거 검색 · 설명 리포트

ai_agent.py가 기록을 모으고, paper_kb.py / retrieval.py가 근거를 검색합니다. SQLite 개인 EMR → 환자별 emr_chunks 로컬 벡터 검색을 함께 전달합니다. 논문·과거 분석·개인 EMR 컬렉션을 분리하며 /emr에서 실제 연결을 확인합니다. LLM은 이미 계산된 판정의 이유와 변화를 설명합니다. report_trace.py는 실제 검색 질문·임베딩·벡터/BM25/RRF 검색·충분성·작성·저장을 제한된 RAM 타임라인으로 전달합니다.

설치 기준과 좌표 보정

mmWave 포인트는 설치 높이와 하향각으로 바닥 기준 좌표를 계산합니다. ToF 격자 방향은 실제 수신값과 설치 방향을 확인해 맞춥니다. 높이·각도만으로 상하 반전을 단정할 수 없습니다.
