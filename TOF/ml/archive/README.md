- 데이터: `TOF/dataset/`의 2026-07-07 촬영, 1명·하루·18세션·6,806프레임(정지 자세만).
- 평가: 클래스별 시간순 앞 70% 학습 / 뒤 30% 평가(999쌍)에서 97.9%. 배포 모델은 전체 데이터로 재학습해 자체 성능 수치는 없다.
