# Bed C 모델 · 2026-11-04

- `rf-real/raw_rf.joblib`: 실측 8,106쌍으로 학습. 실제 사람 단위 교차검증 정확도 61.15%, macro-F1 0.5906.
- `cnn-xgboost-synth50/`: 실측 8,106쌍과 합성 4,053쌍으로 학습. 실제 사람 단위 교차검증 정확도 46.84%, macro-F1 0.4441. TorchScript CNN의 `features()`로 64개 특징을 구해 `XGBClassifier.load_model()`로 읽은 JSON 모델에 입력한다.

두 센서는 발치 tof1, 머리맡 tof2 순서다. 수신 시각 차이가 250ms 이내인 프레임을 중복 없이 1:1로 짝짓는다. 학습은 세션 앞뒤 1초를 제외했다. RF는 발치 64칸과 머리맡 64칸을 이어 붙인 원시 거리 배열을 사용한다. 실패 값은 -1이다. CNN 입력은 [배치, 센서, 채널, 행, 열] = [N, 2, 3, 8, 8] float32이며 채널은 거리/4000, (빈 침대 기준−거리)/4000, 유효 마스크 순서다. 거리 유효 범위는 0 초과 4000mm 이하이며 무효 칸은 0으로 채운다. 차이 채널은 두 값 모두 유효할 때만 계산하고 ±4000mm로 제한한다. 학습 기준은 이 묶음의 `training_baseline.json`에 들어 있다. 클래스 인덱스와 센서별 내장 기준은 각 `preprocessing.json`을 따른다.

사람별 교차검증 상세는 `metrics.json`, 학습 설정과 라이브러리 버전은 `paper_record.json`에 있다. Pi CPU 성능은 미측정이다.
