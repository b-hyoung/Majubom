촬영 보완 사항

받은 피드백

핵심: 센서 설치 모습 · 위험 감지 화면 · 보호자 알림 결과

  1. 실제 사용한 센서 3종이 모두 보이도록 근접 촬영하고, 센서명과 설치 위치 표시
  2. 실험 영상과 모니터링 대시보드를 더 크게 배치
  3. 가운데 대시보드가 너무 어두워 감지 결과를 확인하기 어려움. 밝기와 가독성 개선 필요
  4. 정상 상태 → 위험 행동 감지 → 위험 알림 발생 과정에 맞춰 자막과 내레이션 추가
  5. 민혁이 모자와 마스크를 벗고 자연스러운 복장으로 재촬영 필요. 환자복이면 더욱 좋고, 불가하면 더 편한 일상복
  6. 전체 영상은 총 3분 — 데모 영상은 30초 내외 + 나머지 PPT 설명. 센서 융합 기술과 위험 감지 결과가 명확하게 드러나도록 수정
  7. 앱 출력뿐만 아니라 스피커를 통해 위험 알림 음성 출력 필요
