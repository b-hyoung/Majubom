# 카메라 기반 침대 자세·움직임 분석 AI

카메라 영상으로 침대 위 사람의 관절과 자세를 분석·기록하고, 향후 ToF·mmWave의 독립 측정 결과와 비교하는 프로젝트입니다.

**현재 단계: 실제 침대 영상 평가 준비.** 기본 0.7은 신체 형태 후보와 침대의 영상상 관계를 따로 계산합니다. 실제 누움·앉음 확정은 후속이며, 이전 0.6의 세 자세 예측은 비교 모드로 유지합니다. 관절·자세의 정답 기반 정확도는 미검증이며, 이탈·복귀 판정은 미구현입니다.

현재 두 카메라 입력으로 [실시간 임시 3D 표시](docs/guides/EXPERIMENTAL_3D_PREVIEW.md)도 지원합니다. 실제 관절을 사용하며 거리·방 정렬은 미검증이고 데모/검증된 복원/기록과 구분합니다.

[4단계: 3D 관절 + 침대 위치의 실험적 6자세 분류](docs/guides/SIX_POSTURE_3D.md)를 추가했습니다. 먼저 두 영상의 침대 모서리를 등록하며, 임시 3D의 예측을 실제 정답이나 학습 라벨로 저장하지 않습니다.

침대가 기울어져 보이거나 관절이 가릴 때의 [침대 수평 표시·예외 처리 범위](docs/guides/PREVIEW_EXCEPTION_HANDLING.md)도 확인할 수 있습니다.

[관절 실패 대응: 논문 원문 9편·GPU 비교·적용 결과](docs/research/POSE_RECOVERY_REVIEW_2026-11-01.md)를 추가했습니다. 부분 관절 재탐색·주기적 IMAGE 확인·GPU 통신 복구와 설정형 CUDA 사람 검증을 적용했습니다. 이불 무늬 오검출을 검사했으며 작은/먼 사람은 보류될 수 있습니다. RTMPose-s/m 비교 도구와 별도 CUDA 환경도 준비했습니다. 어려운 옆누움의 최종 관절 수 개선은 확인하지 못했으며, 실제 정확도 향상으로 보고하지 않습니다.

[5·6단계: 카메라 자세와 ToF 동기 저장·GPU 학습 안내](docs/guides/TOF_TRAINING.md)를 추가했습니다. Majubom의 8×8 ToF 두 센서를 읽고 품질·안정 시간·수신 시차 조건을 통과한 데이터만 저장합니다. CNN·CNN+GRU와 각 특징 추출기의 LightGBM·Random Forest·XGBoost를 같은 그룹 분할에서 비교합니다. RTX 5070에서 합성 데이터 실행을 확인했으며 실제 ToF 연결·정답 기반 성능은 미검증입니다. 현재 미검증 3D는 기본 엄격 수집에서 제외하고, 명시적 의사 라벨 수집 후 검토하는 경로를 별도로 제공합니다.

## 시작하기

**최신 보정 방식:** [마커 없는 자동 정적 배경 보정](docs/guides/AUTOMATIC_CALIBRATION.md)이 기본입니다. 사람이 비킬 수 있도록 **시작 지시 후 10초 대기**하고 새 영상을 수집합니다. 내부값·기준 길이가 없는 결과의 한계와 실패/삼각측량 차단을 구분합니다. 화면/수동 보정은 선택 기능으로 유지합니다.

**추가: 두 카메라 보정·실시간 3D 방 모니터.** 기존 작업실 상단 **3D 공간 모니터 ↗**에서 엽니다. [설치·촬영·보정·좌표계 안내](docs/guides/ROOM_MONITOR.md). 실제 카메라 보정/3D 정확도는 아직 검증하지 않았습니다.

인쇄 없이 [화면 패턴 보정·GPU·부드러운 3D 데모](docs/guides/SCREEN_CALIBRATION.md)를 사용할 수 있습니다. 화면 렌더링과 실제 관절 추론 FPS, 시뮬레이션과 실제 복원을 구분해 표시합니다.

이미 설치한 환경에서는 프로젝트 폴더의 PowerShell에서 실행합니다.

```powershell
& .\.venv\Scripts\python.exe -m bed_pose live
```

**입력 추가 → 카메라/영상 선택 → 필요 시 침대 모서리 네 점 지정 → 측정 시작 → 측정 종료** 순서입니다. 종료할 때는 ‘작업실 종료’ 또는 Ctrl+C를 사용합니다. 브라우저 탭만 닫으면 측정은 계속됩니다.

## 무엇을 할 수 있나요?

| 기능 | 현재 범위 |
|---|---|
| 입력 | 이름으로 카메라 선택, 해상도·FPS 요청, 저장 영상 분석, 여러 입력 동시 표시 |
| 분석 | 관절·실루엣·신체 형태 후보·침대 관계, 선택적 CLIP 자세 예측. 실제 정답과 구분 |
| 측정 | 선택적 네 점 영역과 개별 형태 기록, 두 입력 그룹의 단일 계획 측정 |
| 기록 검토 | 기록 목록·시간축·프레임별 근거, 원본 저장 영상과 정확한 프레임 대조 |
| 두 카메라 | 침대 영역을 확인해 빈 침대에서도 측정 시작. 각 화면에서 침대 안 사람을 주변 인물보다 우선하고 수신 시각이 맞으면 CLIP 점수 통합(동일인 인증 아님). 한 시점만 사용하면 명시. 기존 기록의 라벨 일치 방식 유지 |

보정된 왜곡 제거 영상의 두 카메라 3D 관절을 기록 결과에 추가하는 실험 기능은 [3D 관절 근거 사용법](docs/guides/STEREO_DEPTH.md)을 참고하세요. 선택적으로 기존 3D 규칙을 적용해 깊이와 영상 판정이 일치하는 결과를 낼 수 있습니다. 실시간 보정·복원은 별도 [3D 공간 모니터](docs/guides/ROOM_MONITOR.md)에서 제공합니다. 실제 정확도 검증은 후속입니다.

두 카메라의 가려진 관절 상호 보완, 노출 동기화·실시간 깊이 기반 자세 판정, 자세 전환 안정화, 이탈/복귀, 자동 침대 인식과 외부 센서 비교는 후속입니다. 선택적 영상 녹화는 분석 프레임과 로그를 연결하며 전체 카메라 수신 프레임 녹화는 후속입니다.

## 앞으로의 방향

관절 추정 실증 → 독립 자세·이벤트 측정기 → ToF/mmWave 비교 → 운영 기능 완성 순서입니다. 현재는 실제 침대 영상으로 세 자세 기준선을 평가할 준비 단계이며, 자동 침대 인식·선택적 녹화·단일/순차 계획 등 남은 목표도 유지합니다. [전체 로드맵과 단계별 체크리스트](ROADMAP.md)에서 현재 위치·다음 작업·완료 조건을 확인하세요.

CLIP ViT-B/16 실행 제공자·0.10 최종 조합·[정답 주석 평가 CLI](docs/guides/RECORD_REVIEW.md#posture-accuracy)를 구현했습니다. **CLIP 가중치는 별도 준비**하며 미사용 시 기존 0.7입니다. 관절·자세의 정답 기반 정확도는 미검증입니다. [CLIP 설치·선택](docs/guides/LIVE_MEASUREMENT.md#clip) · [상세 계약](docs/design/AUTOMATIC_POSTURE.md).

## 결과를 해석할 때

- 적합도는 확률이나 정확도가 아닙니다. 현재 0.65 기준과 가중치는 실험 초기값입니다.
- 목표 자세·AI 예측·확인된 정답·외부 센서 결과를 분리합니다.
- 개발 테스트와 기록 무결성 검사는 실제 사람의 자세 정확도 검증을 대신하지 않습니다.
- 원본 영상·개인정보·모델 파일은 GitHub에 올리지 않습니다.

Windows와 Apple Silicon Mac의 공통 실행 경로(CPU/CUDA/MPS)를 제공합니다. 현재 Mac 패키지 대상과 설치 방법은 [측정 작업실 안내](docs/guides/LIVE_MEASUREMENT.md#macos-설치와-실행)를 확인하세요. Mac 실기기 실행 검증과 Intel Mac 대응은 별도입니다.
