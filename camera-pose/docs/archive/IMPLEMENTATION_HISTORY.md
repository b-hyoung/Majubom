# 구현 이력

> **과거 이력/호환 자료:** 본문에서 말하는 현재·미구현·다음 작업은 작성 당시 기준입니다. [현재 상태](../PROJECT_STATUS.md) · [문서 목차](../README.md).


[현재 지원 범위](../PROJECT_STATUS.md) · [프로젝트 홈](../../README.md)

아래는 구현 당시의 기록입니다. ‘현재’, 버전 번호와 후속 작업은 해당 작성 시점 기준이며 현재 지원 범위를 대체하지 않습니다.

## 브라우저 표시 화질 개선 · 2026-10-28

상단 **화질**에서 고화질/표준을 전환합니다. 기본 고화질은 긴 변 최대 1920px·JPEG 95, 표준은 기존 긴 변 1280px·JPEG 85입니다. 16:9 가로 입력에서는 각각 최대 1080p/720p이며 원본보다 확대하지 않습니다. 화면 아래에 실제 입력/전달 해상도를 표시하고 여러 화면도 크기·픽셀 밀도에 맞춰 그립니다. 카메라 설정·AI 입력·판정 기준은 유지합니다. [기준과 한계](../guides/PREVIEW_QUALITY.md).

## 측정 기록 시간축 요약 · 2026-10-28

왼쪽 **측정 기록 보기 → 완료 기록 선택**에서 자세 분포·자세별 적합도 평균/최소/최대·보류 사유·실루엣 충돌 구간을 확인합니다. 그래프를 클릭하면 해당 구간의 원본 프레임으로 이동하고, 슬라이더와 첫 보류/충돌 이동 버튼도 사용할 수 있습니다. 저장 영상의 원본 PTS와 측정 수신 시간을 구분합니다. 프레임 수 집계이며 자세 유지 시간·정확도나 새로운 판정이 아닙니다. [사용법·검사 범위](../guides/RECORD_REVIEW.md#timeline).

## 실루엣 영상 표시 · 2026-10-28

상단 **실루엣 표시**를 켜면 선택된 인물 영역이 영상 위에 반투명 보라색으로 표시됩니다. **관절 표시**와 독립적으로 전환하고 여러 화면 보기에도 적용합니다. 같은 프레임·대상의 마스크만 표시하며, 전체 마스크 미리보기는 저장하지 않습니다. 기존 자세·점수는 유지합니다. [표시와 한계](../design/SILHOUETTE_SUPPORT.md#영상-위-실루엣-표시--2026-10-28).

## 실루엣·관절 보조 검사 · 2026-10-28

HTML 작업실의 **영상 보조 근거**에서 인물 실루엣과 몸통 7지점 주변의 일치·충돌·확인 불가를 표시합니다. 같은 프레임/후보/표시 관절의 대응을 확인하고 희소 마스크 출력값과 보조 결과를 기록·조회·CSV에 연결했습니다. **가중치·0.65 기준·최종 자세 판정은 유지**합니다. 같은 모델의 보조 추정이며 실제 관절/자세 정확도 검증은 아닙니다. [사용법·초기값·한계](../design/SILHOUETTE_SUPPORT.md).

## 측정 기록 조회 · 2026-10-28

왼쪽 **측정 기록 보기**에서 이전 측정을 열고 저장 당시 프레임별 자세·적합도·보류/참고 사유를 확인할 수 있습니다. 목록과 프레임 페이지, 기록 검사·미완료/실패 구분과 이전 형식 읽기를 지원합니다. 카메라 없이도 조회할 수 있고 가중치·0.65 기준·최종 판정 로직과 원본 기록은 변경하지 않습니다. [사용법과 지원 범위](../guides/RECORD_REVIEW.md#browse).

## 가중 적합도 판정 · 2026-10-28

기본 자동 규칙 **0.5**는 자세별 독립 적합도 중 **최고 점수가 0.65 이상이면 판정**합니다. 1·2위 차이가 작아도 1위를 출력하고 참고 안내만 표시합니다. 점수가 동점이거나 필수 관측 조건이 부족하면 보류합니다. 2D·추정 3D 비중과 기준은 실험 초기값이며 확률·실제 정확도가 아닙니다. 화면·원본 기록·CSV에 점수와 사용 근거를 남깁니다. [계산·기준·이전 기록 호환](../design/WEIGHTED_POSTURE.md).

## 이전 구현 이력: 새 특징의 최종 자세 판정 연결 · 2026-10-28

기본 자동 규칙을 **0.4**로 변경했습니다. 몸통 기준 어깨·골반의 2D 벌어짐/어긋남으로 누운 방향을 구분하고, 2D가 애매하면 같은 후보의 추정 3D로 바로 누움·옆누움 후보를 판단합니다. 명확한 근거 충돌은 보류하며 화면에 사용 근거를 표시합니다. 추가 학습·실제 정확도 검증은 미수행이고 기존 0.1~0.3 기록은 당시 규칙으로 검사합니다. [동작·초기값·시점 한계](LYING_ORIENTATION_RULES.md).

## 이전 구현 이력: 2D·3D 근거 비교 · 2026-10-28

AI 자세 판정의 **2D·3D 근거 비교**에서 같은 프레임의 기존 판정, 몸통 기준 어깨·골반 특징과 MediaPipe 추정 깊이 차이를 확인할 수 있습니다. 측정 기록의 재계산 검사와 CSV 내보내기도 지원합니다. 이 단계에서는 새 특징을 판정에 연결하지 않고 기존 자동 규칙 0.3을 유지했습니다. 현재는 위의 0.4를 사용합니다. 추정 3D는 침대 기준 실제 높이가 아닙니다. [화면·명령·특징 의미와 검증 범위](../design/POSTURE_EVIDENCE_COMPARISON.md).

## 자동 자세 판정 검수 · 2026-10-28

규칙 0.3에서 누움 후보에 불필요한 하체 각도 실패를 분리하고, 보류 안내와 이전 기록의 재계산 호환을 점검했습니다. 전체 169개 검사와 브라우저 확인을 통과했습니다. 관절 품질·시점 의존성·전환 안정성 및 실제 정확도는 미검증입니다. [수정 사항과 남은 위험](../reviews/AUTOMATIC_POSTURE_REVIEW.md).

## 관절 부족 보류 조건 수정 · 2026-10-28

사용자 보고의 ‘어깨·골반·무릎·발목 좌표 부족’을 확인하고 하체 누락 시 누움 조건의 몸통으로 비교하는 자동 규칙 0.2를 연결했습니다. 앉음/서 있음 구분과 몸통 정보 부족은 보류하고 기존 0.1 기록은 당시 규칙으로 검사합니다. 최근 최대 300개 처리 프레임의 보류 비율·주요 사유를 입력별로 표시합니다. 실제 촬영 조건의 보류율/정확도 개선은 미검증입니다. [조건과 집계 의미](../design/AUTOMATIC_POSTURE.md).


## 네 점 침대 영역 · 2026-10-28

침대 모서리를 순서대로 네 번 클릭해 지정하고 점 이동·마지막 점 취소·지정 취소를 지원합니다. 볼록 영역 검사, 실제 다각형 내부 여부, 단위 사각형 대응 상대 좌표와 자동 자세 판정/원본·그룹 기록 검사를 연결했습니다. 기존 사각형 기록은 유지하며 네 점을 포함한 통합 입력은 0.3 형식입니다. [사용법과 좌표 의미](../guides/BED_REGION.md).


## 기준 등록 없는 자동 판정 · 2026-10-28

사용자가 수동 기준 등록 없이 자동 판단하도록 요청해 실제 카메라/영상의 기본을 실험용 2D 기하 규칙으로 변경했습니다. 침대 영역 지정 후 바로 누움·옆으로 누움·걸터앉음 또는 보류를 출력합니다. 기본 사선·측면 배치와 위 시점 설정의 차이가 있으며 위 시점은 걸터앉음을 판정하지 않습니다. 임계값·정확도는 아직 미검증입니다. 두 시점은 시간/대상 게이트와 양쪽 라벨 일치로 결합합니다. 기준 등록 화면은 기본 흐름에서 제거하고 이전 기록 호환은 유지합니다. [사용법·가정·한계](../design/AUTOMATIC_POSTURE.md).


## 이전 구현 이력: 기준 자세 비교 · 2026-10-28

사용자가 실제 자세 판정을 요청해 카메라별 세 기준 예시를 등록하는 최근접 특징 비교를 연결했습니다. 소수 수동 라벨을 이용하는 지도 방식이며 신경망 가중치 학습은 수행하지 않았습니다. 분류 결과/보류·라벨별 거리·원본 기록 검사와 두 시점의 수신 시각/대상 게이트를 통과한 거리 결합, 종료 후 FIFO 쌍의 통합 예측 기록을 제공합니다. 검증된 범용 분류기·범위 밖 자세 탐지·실제 정확도 확보를 의미하지 않습니다. [사용법과 한계](REFERENCE_POSTURE.md).
