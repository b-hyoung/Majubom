> **과거 이력/호환 자료:** 본문에서 말하는 현재·미구현·다음 작업은 작성 당시 기준입니다. [현재 상태](../PROJECT_STATUS.md) · [문서 목차](../README.md).


**후속 현재 구현:** [가중 규칙 0.5](../design/WEIGHTED_POSTURE.md)는 최고 적합도와 최소 기준으로 판정하며 1·2위 차이는 참고 안내에만 사용한다. 아래는 0.4의 구현 이력이고 당시 기록은 그대로 재현한다.

2026-10-28. 사용자가 비교값 표시를 넘어 새 특징을 실제 판정에 적용하도록 요청했다. 추가 학습 없이 **몸통 기준 2D 배치와 같은 후보의 추정 3D**를 최종 바로 누움·옆으로 누움 판정에 연결했다. 실제 카메라·저장 영상의 기본 자동 규칙은 `automatic-posture-rules-0.4`다. 학습된 범용 분류기나 정확도 검증 완료를 의미하지 않는다.

## 실행과 확인

```powershell
& .\.venv\Scripts\python.exe -m bed_pose live
```

카메라 또는 저장 영상을 연결하고 침대 영역을 지정한다. 기존처럼 오른쪽에 바로 누움·옆으로 누움·걸터앉음 또는 판정 보류를 표시한다. 새 기준 등록·누움 확인 버튼·추가 모델 파일은 필요하지 않다. 합성 데모의 자동 판정은 기존처럼 기본 꺼짐이다.

누운 방향을 판단한 프레임에는 **판정 근거: 몸통 기준 2D**, 또는 **몸통 기준 2D + 추정 3D**를 표시한다. `2D·3D 근거 비교`를 펼치면 현재 라벨과 판정·보류에 실제 사용한 경로를 확인할 수 있다. 새 특징으로 누운 방향을 판단하기 전에 다른 조건에서 보류된 경우에는 그 사실을 표시한다. 3D 정보가 없는 입력도 2D만으로 판정할 수 있다.

## 실제 결정 흐름

1. 기존 처리·대상·침대·몸통 가용성 조건을 검사한다. 기존 0.3의 서 있음 거부·걸터앉음 조건·촬영 시점/몸통 방향 보류·위 시점의 앉음 모호 조건을 유지한다.
2. 기존 누움 후보에 해당할 때 어깨선·골반선의 **몸통에 수직인 벌어짐**, **몸통 축 방향 어긋남**, 선 사이 각도를 계산한다. 과도한 어긋남·교차·어깨/골반의 상반된 폭 단서는 보류한다.
3. 두 벌어짐 모두 작으면 옆누움, 둘 다 크면 바로 누움 후보를 만든다. 전체 관절 간 거리 대신 성분을 분리하므로 축 방향 차이를 옆으로 벌어진 폭으로 혼동하지 않는다.
4. MediaPipe 원본의 같은 후보에서 대응이 확인된 어깨·골반 3D를 가져온다. 두 쌍의 깊이 방향 성분이 크고 같은 부호이면 옆누움 보조 단서, 둘 다 작으면 앞면/뒷면 방향의 보조 단서로 사용한다. 이는 촬영 배치에 의존하는 **미검증 가설**이며 실제 침대 지지·중력 측정이 아니다.
5. 2D가 애매하고 3D가 일관된 방향을 제시하면 해당 후보로 최종 판정한다. 명확한 2D와 명확한 3D가 충돌하면 `2D 배치와 추정 3D 방향이 다름`으로 보류한다. 3D가 없거나 방향이 애매하면 충분한 2D 단서만 사용한다. 잘못된 2D 몸통 축이나 어깨/골반 충돌을 3D로 덮지 않는다.
6. 바로 누움에는 기존 코·양쪽 눈과 해부학적 좌우 투영 방향 단서를 계속 요구한다. 이 약한 조건이 엎드림 검출기의 정확도를 보장하지 않는다. 불확실하면 직전 라벨을 유지하지 않고 현재 프레임을 보류한다.

**누운 방향 구분과 누워 있다는 판단은 별개**다. 현재 사선/측면 규칙에서 몸통 세로 비율이 누움 조건 밖이고 기존 자세 조건으로 해석할 수 없으면 여전히 `촬영 시점 또는 몸통 방향 불확실`이 나올 수 있다. 이번에 그 조건을 강제로 풀지는 않았다. 기울어진 서 있는 사람을 누움으로 바꾸는 방식도 사용하지 않는다.

## 실험 초기 설정

| 설정 | 값 | 목적 |
|---|---|---|
| `side_span_max` | 0.22 | 어깨·골반의 수직 성분/몸통 길이가 모두 이하면 2D 옆누움 후보 |
| `front_span_min` | 0.40 | 두 비율이 모두 이상이면 2D 바로 누움 후보 |
| `body_axial_max` | 0.35 | 몸통 축 방향 어긋남/몸통 길이의 최대값; 2D 및 3D 몸통 일관성에 사용 |
| `body_line_angle_max` | 30° | 어깨선·골반선 사이 방향 부호를 무시한 각도의 최대값 |
| `world_side_depth_min` | 0.75 | 두 쌍의 \|추정 Δz\|/각 3D 관절 간 거리가 모두 이상이면 옆누움 보조 단서 |
| `world_front_depth_max` | 0.35 | 두 깊이 비율이 모두 이하면 앞면/뒷면 보조 단서; 얼굴 조건 별도 |
| `world_depth_difference_max` | 0.25 | 부호 있는 어깨·골반 깊이 비율 차이의 최대값 |

위 수치는 자료에서 보정하거나 논문에서 검증된 기준이 아닌 **구현 초기 실험값**이다. 프로필과 모델 ID 해시에 모두 포함해 기록하고 실행 버전별로 재현한다. 미터 높이·확률·신뢰도 임계값이 아니다. 과도한 몸통 어긋남이 실제 자세 변화인지 관절 오류인지도 별도 확인해야 한다.

## 코드·기록과 이전 버전

- `posture.py`: 선택된 단일 후보의 2D와 원본 3D 대응을 확인해 분류기에 전달한다. 목표 자세·정답·외부 센서는 입력에서 제외한다.
- `lying_orientation.py`: 누움 후보의 새 방향 규칙을 수행한다. `automatic_posture.py`가 기존 자세 조건 뒤에서 호출하며 그 출력이 실제 `posture_assessment`와 `posture_prediction` 라벨이 된다.
- `rule_features.orientation_decision`: 2D/3D 방향 후보·사용 경로·계산 특징·가용 사유를 기록한다. `existing_gate`는 새 방향 규칙이 사용되기 전의 기존 판정 경로다.
- `live-inspect`: 당시 프로필로 라벨·근거를 재계산한다. **0.1·0.2·0.3 기록의 입력·프로필·판정 로직은 유지**하고, 새 3D 입력을 그 버전들에 적용하지 않는다.
- CSV 보고서 0.2는 `decision_source`, `orientation_2d`, `orientation_3d`와 원본 자동 프로필을 추가한다. 이전 기록을 현재 규칙으로 재분류하지 않는다. 기존 CSV 필드 `baseline_label`은 호환 이름으로, 지정한 기록에 저장된 당시의 최종 라벨이다.
- `posture_evidence`의 `combined`는 특징 가용성 묶음이며 별도 라벨은 생성하지 않는다. 0.4에서는 `classifier_status`에 `used_by_automatic_rules` 또는 `not_used_by_automatic_rules`를 남긴다. 실제 최종 라벨과 연결은 `posture_assessment`와 `rule_features.orientation_decision`으로 확인한다. 이전 규칙의 `not_configured` 값은 과거 기록 재계산 호환을 위해 유지한다.

단일 카메라에서도 동작한다. 두 카메라는 각 시점의 최종 라벨에 기존 대상·시간·일치 조건을 적용하며 3D 좌표를 삼각측량하거나 평균하지 않는다.

## 검증 한계와 남은 작업

모의 관절로 기존 보류→2D 옆누움, 2D 불확실→3D 보조 바로 누움/옆누움, 근거 충돌 보류, 좌표 대응·다인 선택, 얼굴·침대·서 있음 조건, 회전/이전 프레임 독립성, 새 기록 재계산과 변조 거부, 0.1~0.3 호환 및 CSV를 검사한다. 전체 193개 개발 검사를 통과했다. Chromium에서 3D 보조로 최종 바로 누움/옆누움 출력, 충돌·불확실·3D 결측 보류, 2D 단독 옆누움, 여러 화면·390/1440/2560px 너비·입력 제거와 JavaScript 오류 없음을 확인했다. 이러한 검사는 코드의 의도한 동작 검증이며 사람 영상의 분류 정확도 측정이 아니다.

실제 침대 영상의 시점·가림·체형·뒤집힘·전환에 대한 정확도와 보류율은 아직 미검증이다. 단안 3D는 같은 영상에서 추정한 값이므로 독립 실측 근거가 아니며, 2D와 함께 틀릴 수도 있다. 카메라 시점·미러링에 따라 해부학적 앞면과 실제 침대 자세가 다르게 해석될 수 있다. 다음은 별도 정답이 있는 영상에서 이전 0.3과 0.4의 오분류·보류율을 함께 비교해 초기값과 사용 조건을 조정하는 것이다.
