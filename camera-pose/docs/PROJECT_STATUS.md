## 처리 자원·표시 개선 · 2026-10-30

CLIP 실행 장치는 기본 자동 선택(CUDA 지원 시 CUDA, 아니면 CPU)하며 CPU 연산 스레드의 기본 상한을 4로 제한합니다. 입력별 읽기·관절·이미지 처리 시간을 표시하고 실험 기록에 실제 CLIP 실행 설정을 남깁니다. 긴 상태 설명으로 형태 적합도 제목이 압축되던 열 배치를 수정했습니다. 실제 PC의 FPS 개선은 미검증이며 [속도 확인 방법](guides/LIVE_MEASUREMENT.md#처리-속도-확인과-실행-장치)을 따릅니다.

## 누움 출력 통합

화면과 기록 시간축에서 기존 `supine` 및 방향 미확인 `lying`을 `누움`으로 표시합니다. 새 안정화 버전 0.2에서는 두 값이 오가도 동일 자세로 처리하며, 이전 0.1 기록의 재검사는 기존 방식으로 유지합니다. 원본 자세 라벨·방향 점수·정답 평가 입력은 보존하므로 상세 데이터에서는 두 근거를 구분할 수 있습니다.

2026-11-01 실제 화면 패턴 촬영 중 Windows 한글 경로에서 OpenCV 이미지 저장 실패를 확인해 PNG 인코딩/바이트 파일 입출력으로 수정했습니다. 촬영 이미지는 로컬에 저장되며, 양쪽 코너 검출을 확인한 쌍만 유효 자료로 셉니다. 실제 보정값 계산은 아직 완료되지 않았습니다.

2026-11-01 화면 체커보드 실측 가로 0.32m로 양쪽 54코너가 검출된 15쌍을 실제 저장하고 보정 후보를 계산했습니다. 스테레오 재투영 RMS 0.339px, 기준 패턴 오차 1.673px이나 추정 기준선 4.153m가 사용자 제공 약 3.3m와 25.8% 달라 실측 정확도 미검증입니다. 결과는 target_world이며 방 정렬/관절 삼각측량에 적용하지 않았습니다. 로컬 .monitor/guided-calibration-assessment.json에 검증 한계를 저장했습니다.

같은 촬영의 기준선은 사용자 후속 확인값 약 3.6m로 수정했습니다. 후보의 4.153m와 차이는 약 15.4%이며, 보정 후보/방 정렬의 미검증 상태는 유지합니다.
