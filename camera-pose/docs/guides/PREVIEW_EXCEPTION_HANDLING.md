# 임시 3D의 예외 처리와 침대 수평 표시

2026-11-01 사용자 요청: 눈에 띄는 관절 떨림, 한쪽 관절 가림과 입력 전환, 침대가 기울어진 표시를 먼저 처리합니다. 가능한 예외를 구분하고 검증하며 모든 장면의 검출/정확도를 보장한다고 주장하지 않습니다.

## 침대 기준의 공통 표시 좌표

등록한 네 모서리의 최적 평면 법선을 Y, 머리→발 방향을 Z, 오른손 직교축을 X로 잡습니다. 침대 중심이 표시 좌표 `(0, 0.65, 0)`이 되도록 **모든 관절·카메라·침대에 같은 회전 R과 이동 d**를 적용합니다. `X_display = R X_preview + d`이며 카메라는 `R_camera_new = R_camera_old R.T`, `t_camera_new = t_camera_old - R_camera_new d`로 바꿉니다. 따라서 카메라 투영 관계와 몸/침대 상대 기하는 유지됩니다.

바닥은 표시 Y=0, 윗면은 사용자 제공 높이 65cm에 표시합니다. 회전·이동만 수행하고 거리 스케일을 강제로 바꾸지 않습니다. `unit=unverified_candidate_units`, `coordinateSystem=bed_preview`, `scale_verified=false`입니다. 65cm를 표시 원점의 높이로 쓴 것이며, 카메라 거리/신체 크기가 정확해졌다는 뜻은 아닙니다.

네 모서리에 약간의 비평면 오차가 있을 수 있어 **표시 면만** 최적 평면에 투영해 수평으로 그립니다. 원래 등록 좌표와 오차는 보존하고 분류도 원래 좌표를 사용합니다. 프레임마다 사람 자세에 맞춰 침대를 돌리지 않습니다. 침대가 등록돼 있으면 사람이 없어도 침대 중심으로 시점을 잡습니다. '위/정면/측면/침대 중심'도 같은 기준입니다.

기본은 침대 기준이며 `침대 기준 수평 정렬` 버튼으로 다시 선택할 수 있습니다. 서 있음/누움 기준은 별도 선택으로 남깁니다. 표시 축 기준은 후보 카메라 행렬 해시와 묶어 저장·복원합니다. 침대/카메라를 실제로 움직였거나 후보가 바뀌면 재등록해야 합니다. 물리 이동을 자동 인증할 수는 없습니다.

## 처리하는 예외

| 상황 | 현재 처리 |
|---|---|
| A 또는 B 한쪽만 사람/관절 출력 | 관측이 충분한 쪽의 SDK world + PnP 추정 3D. 단일 카메라/깊이 추정을 표시 |
| 양쪽 중 한쪽의 관절이 더 많음 | 어깨·골반과 다리 관측을 포함해 근거를 비교. 서로 다른 좌표 근거를 관절별로 섞지 않음 |
| 삼각측량 관절 수는 많으나 몸통 누락 | 몸통이 있는 단일 카메라 후보를 우선 |
| 입력 방식이 짧게 번갈아 바뀜 | 이전 방식의 새 관측이 남으면 600ms 전환 확인. 불가능해지면 즉시 대체 |
| 프레임 재전달/중복 폴링 | observation_id로 같은 관측을 중복 표시 처리하거나 안정 시간으로 누적하지 않음 |
| 연결 종료/낡은 프레임/미래 타임스탬프 | 선택한 관측의 시간·연결 상태를 검사. 300ms 또는 설정 만료 중 짧은 한계 이후 출력 비움 |
| 여러 사람을 모델이 반환 | 합치지 않고 보류. 단일 대상 GPU 모델이 반환하지 않은 추가 인물은 검출 보장 불가 |
| NaN/Inf/잘못된 관절·신뢰도/중복 ID | 제외 또는 해당 패킷 보류 |
| 비정상적으로 긴/짧은 팔다리·관절 튐 | 몸통 비율로 비정상 관절과 그 하위 관절 제외. 결측 관절 생성 안 함 |
| 좌표 흔들림/단발 점프 | 표시용 deadband, 60~160ms 적응형 평활화, 전환 300ms, 새 프레임에서 점프 재확인 |
| 관절이 계속 튀어 재확인 실패 | 이전 좌표는 표시 단계에서 최대 250ms까지만 유지 후 제외. 원래 관절이 없으면 즉시 제외 |
| 무릎 한쪽 가림 | 관측된 무릎·몸통·침대 근거로 제한 후보. 누락 경고와 최소 1.2초 안정화 |
| 무릎 양쪽 가림 | 수평 몸통·침대 안쪽/평면 근처·매우 강한 누운 방향 조건을 모두 만족할 때만 제한 후보. 무조건 누움으로 처리하지 않음 |
| 코 가림 | 눈 관측이 있으면 방향 일치 확인 후 제한 후보. 얼굴 근거 전무/충돌하면 바로 누움·엎드림 보류 |
| 앉음의 무릎 가림 | 한쪽 허벅지로 제한 후보 허용. 양쪽 무릎 없으면 보류 |
| 침대 가장자리의 발목 가림 | 걸터앉음을 강제하지 않고 보류 |
| 침대 밖/서 있음/전환/애매한 각도 | 별도 사유로 보류. 6개 클래스 중 하나로 강제하지 않음 |
| 잘못된/비평면/교차된 침대 모서리 | 등록 거부. 사용자에게 대응/평면 확인 안내 |
| 침대 지정 중 카메라 연결 변경 | 지정값 폐기 후 새 영상 요구 |
| 저장 침대 파일 손상/다른 후보 해시 | 잘못된 침대 재사용 안 함. 단일/스테레오 미리보기는 계속 가능 |
| 서버/브라우저 연결 끊김 | 관절/분류 출력 비움. 실제 정답이나 이탈로 바꾸지 않음 |
| 표시 좌표계/침대 좌표계 불일치 | 분류 보류. 원본 기하와 표시 변환 분리 |

제한 후보 점수는 자세 정답 확률이 아닙니다. `accuracy_verified=false`, `eligible_for_recording=false`를 유지하고 기존 CLIP·MediaPipe·자세 판정·녹화 파일을 덮어쓰지 않습니다. 이번 작업에서 영상 녹화나 ToF 학습 정답 저장은 시작하지 않았습니다.

## 확인과 한계

`test_preview_edge_cases.py`는 수평/중심/방향·투영 불변성·분류 불변성·저장 복원, 한쪽/양쪽 무릎 가림, 얼굴 대체, 안정화, 잘못된 입력/팔다리, 미래 시각/여러 사람/연결 변경을 포함합니다. 기존 단일 카메라/보정/방 모니터 검사와 표시 평활화 검사를 함께 수행합니다. 실제 서버에서 침대 법선 `(0,1,0)`, 네 모서리 Y=0.65, 중심 `(0,0.65,0)`, 양쪽 GPU preview 실행을 확인했습니다.

브라우저 조작 도구가 'Work 설정에서 비활성화' 오류를 반환해 이번 변경 화면의 육안 확인은 제한됐습니다. 새 코드는 빌드돼 HTTP 200으로 제공되며 기존 화면은 새로고침해야 합니다. 실제 옆누움의 개선/장시간 안정성·각도/가림별 정확도는 추가 현장 검증 대상입니다. 완전 가림·사람 미검출·오래된 영상·잘못된 보정에서 정확한 3D를 복원할 수 있다고 주장하지 않습니다.

최종 검증: 전체 Python 회귀 518개 실행, 선택 의존성 5개 건너뜀, 나머지 통과(202.362초; 로컬 `outputs/full-tests-exceptions.txt`). 표시 필터 Node 검사 10개와 TypeScript/Vite 빌드 통과. 서버에서 새 정적 자산 HTTP 200과 양쪽 GPU 입력을 확인했습니다.
