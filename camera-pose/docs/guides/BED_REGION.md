# 네 점 침대 영역

[문서 목차](../README.md) · [분야 목차](README.md) · [현재 상태](../PROJECT_STATUS.md)


2026-10-28. HTML 작업실에서 침대 모서리 네 곳을 순서대로 클릭해 볼록 사각 영역을 지정한다. 자동 침대 검출과 실제 물리 경계의 정답 확인은 별도다.

## 사용

1. 개별 영상에서 **침대 영역 지정**을 누른다. 해당 미리보기 프레임을 고정한다. 입력·관절 분석·진행 중인 기록은 계속된다.
2. 시계 또는 반시계 방향으로 모서리 네 곳을 찍는다. 첫 점은 어느 모서리든 가능하다. 1~4 번호와 연결선을 표시하고 네 번째 점에서 자동 적용한다.
3. 지정 중 **마지막 점 취소**, **지정 취소/Escape**를 사용할 수 있다. 선 교차·오목한 순서·중복/일직선·너무 작은 영역은 거부하고 마지막 유효 영역을 유지한다. 마지막 점을 취소하거나 잘못된 점을 이동해 다시 제출할 수 있다.
4. 적용한 뒤 **점 위치 수정**을 누르고 번호 점을 드래그하면 새 영역으로 적용한다. 편집 취소는 기존 영역을 유지한다. **영역 지우기**는 명시적으로 해제한다.
5. 그룹 준비/기록 중에도 수정할 수 있다. 입력 시작/종료/정리·명령 처리 중에는 조작을 제한한다. 입력 전환/종료 시 편집을 이어 붙이지 않는다.

초안 편집 중 서버 분석은 마지막 유효 영역을 사용한다. 네 점이 검사를 통과해 Worker에서 적용된 프레임부터 새 영역 버전을 기록한다. 화면 고정 프레임과 실제 적용 프레임/시각은 다르며 원본의 선택·요청·적용 메타데이터로 구분한다.

## 검증과 저장

`bed_geometry.py`의 공통 함수를 API·Worker·기록 검사·자세 분류·통합 입력 생성에서 사용한다. 원본 이미지 안의 유한한 숫자 좌표 네 개, 같은 방향의 엄격한 볼록 회전 조건을 검사한다. 원본 좌표 기준 면적 16px² 이상·변 길이 2px 이상은 클릭 오류를 거부하는 운영 최소치이며 인식 정확도 기준이 아니다. 단위 좌표 변환이 특이하거나 수치적으로 불안정하면 거부한다.

새 region은 `method=manual_quadrilateral`, `vertices`(클릭 순서), 영상 크기, 정규화한 네 점, 파생 외접 bbox를 저장한다. bbox는 호환·요약용이며 내부 여부와 판정에 외접 사각형을 대신 사용하지 않는다. bbox/정규화 값이 실제 vertices와 다르면 기록 검사가 실패한다. 원본/제어 이벤트의 영역 버전·적용 프레임 이력은 유지한다.

기존 `manual_rectangle` 기록/API와 기본 실행이 아닌 이전 Tk 사각형 입력은 유지한다. live-inspect는 두 형식을 검사하며 기존 파일을 변환하지 않는다. 이전 기준 비교 분류기는 사각형 전용이므로 네 점 영역으로 바꾸면 `reference_geometry_changed`로 보류한다. 기본 자동 판정은 네 점을 지원한다.

## 좌표와 판정

- 내부 여부는 볼록 다각형의 각 변에 대한 부호로 판정하며 경계는 포함한다. 부동소수점 경계 오차만 작은 허용치로 처리한다.
- 네 점을 순서대로 `(0,0),(1,0),(1,1),(0,1)`에 대응시키는 호모그래피로 상대 좌표를 만든다. 첫 점과 순회 방향이 좌표 축을 정한다. 재지정해 시작 모서리/방향을 바꾸면 상대 축도 바뀔 수 있으므로 영역 버전을 따라 해석한다.
- 이는 선택한 침대 면을 평면으로 보는 영상상 대응이다. 사람 관절이 실제로 침대 평면에 있다는 보증, 3D 위치·실측 길이·카메라 외부 보정이 아니다. 실제 침대 모서리를 잘못 찍으면 대응도 틀린다.
- 화면/침대 밖 좌표를 자르거나 누락으로 대체하지 않는다. 투영 분모가 0에 가까워 변환할 수 없으면 bed_xy를 null과 false 마스크로 남기고 원본 픽셀과 내부 여부는 유지한다.
- 자동 판정은 어깨·골반의 다각형 내부 여부와, 변환된 골반 중심의 단위 사각형 경계 거리를 사용한다. 기존 사각형 기록은 이전 계산 순서까지 유지해 재검사 결과를 보존한다. 기존 0.18 등 실험 임계값이 네 점 환경에서 검증된 값이 된 것은 아니다.

네 점이 포함된 그룹의 fusion_inputs는 `two-view-input-0.3-draft`와 좌표 정책을 기록한다. 사각형만 있는 그룹은 0.2, 기존 0.1·0.2도 검사 지원한다. 혼합 구간은 0.3 안에서 각 행의 region method/버전을 따라 계산한다. bed_mask는 화면 내 좌표와 유한한 변환의 가용성이고 inside_bed는 실제 선택 영역 내부 여부다. 자세/목표/정답/센서 라벨의 분리와 통합 예측 재계산도 유지한다.

## 검사 범위

시계/반시계 모서리 대응, 내부/경계/외접 bbox만 포함하는 외부 점, 잘못된 도형/범위/숫자/작은 영역, 메타데이터 변조, 사각형 호환, API 거부 후 입력 유지, 그룹 측정 중 영역 수정과 0.3 특징/검사, 자동 판정·변경 이력 재검사를 확인한다. 브라우저에서는 네 번 클릭·되돌리기·점 이동·Escape·교차 거부·기록·격자·390px 화면을 확인한다. 합성 입력 기반이며 실제 침대 모서리 검출·자세 정확도를 검증한 것은 아니다.

최종 검사: 전체 155개 통과(73.581초). Chromium의 네 점 클릭·마지막 점 취소·점 이동·Escape·교차 영역 거부·측정 기록 검사·격자·390px 화면과 JavaScript 오류 없음을 확인했다. 물리 카메라/실제 자세 정확도 측정은 포함하지 않는다.
