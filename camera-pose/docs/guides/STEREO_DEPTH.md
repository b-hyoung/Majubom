# 보정된 두 카메라의 3D 관절 근거

이 기능은 완료된 두 카메라 그룹의 기존 통합 자세 결과와 같은 정렬 쌍의 3D 관절 추정치를 `posture_with_depth.jsonl` 한 행에 기록합니다. 기본 내보내기는 기존 자세 결과를 변경하지 않습니다. 선택 옵션 `--depth-check`를 사용하면 기존 3D 자세 규칙의 임계값으로 깊이 기반 후보를 계산하고 기존 두 카메라 영상 판정과 일치할 때만 별도의 통합 결과를 냅니다. 두 후보가 충돌하거나 한쪽이 보류되면 통합 결과도 보류합니다. 이 오프라인 내보내기 형식은 기존대로 유지합니다. 새로운 실시간 보정·복원·표시는 별도 [3D 공간 모니터](ROOM_MONITOR.md)를 참고하세요. 두 보정 파일 형식은 다르며 자동 호환되지 않습니다.

## 준비

두 카메라는 측정 중 고정하고 동일한 사람을 각 화면에서 지정합니다. 그룹 측정에 수신 시각 차이를 설정하고 자세 결과를 저장합니다. 다음 보정은 외부 도구에서 실제 촬영 조건으로 수행해야 합니다. 이 오프라인 명령은 보정 계산이나 렌즈 왜곡 제거를 수행하지 않습니다. 새 보정 도구는 별도 ROOM_MONITOR 안내를 따릅니다. **입력 영상 자체가 왜곡 보정된 핀홀 영상인 경우에만** 아래 기능을 사용하십시오. 원본 왜곡 영상에 왜곡 보정 전용 행렬을 적용하면 잘못된 결과가 나옵니다. 해상도, 자르기, 회전, 카메라 위치가 바뀌면 그 입력에 맞게 다시 보정해야 합니다.

JSON의 카메라 배열 순서는 그룹 manifest의 `members` 순서, `input_id`는 해당 그룹의 ID와 정확히 일치해야 합니다. `intrinsic`은 해당 픽셀 좌표의 카메라 행렬, `rotation_world_to_camera`와 `translation_world_to_camera`는 공통 세계 좌표에서 각 카메라 좌표로 가는 변환 `X_camera = R X_world + t`입니다. 두 변환과 좌표 단위는 동일한 보정에서 얻어야 합니다. 예시는 형식 설명용이며 실제 값이 아닙니다.

```json
{
  "version": "stereo-pinhole-0.1",
  "image_coordinates": "undistorted_pinhole_pixels",
  "unit": "m",
  "bed_normal_up_world": [0, 0, -1],
  "quality": {"max_reprojection_error_px": 3, "min_ray_angle_degrees": 2},
  "cameras": [
    {"input_id": "첫번째-입력-ID", "image_size": [640, 480],
     "intrinsic": [[500, 0, 320], [0, 500, 240], [0, 0, 1]],
     "rotation_world_to_camera": [[1, 0, 0], [0, 1, 0], [0, 0, 1]],
     "translation_world_to_camera": [0, 0, 0]},
    {"input_id": "두번째-입력-ID", "image_size": [640, 480],
     "intrinsic": [[500, 0, 320], [0, 500, 240], [0, 0, 1]],
     "rotation_world_to_camera": [[1, 0, 0], [0, 1, 0], [0, 0, 1]],
     "translation_world_to_camera": [-1, 0, 0]}
  ]
}
```

`bed_normal_up_world`는 보정의 세계 좌표계에서 침대 윗면으로부터 위쪽을 향하는 단위 법선입니다. 실제 설치의 법선을 측정해 입력해야 하며 예시 방향을 그대로 사용하면 안 됩니다. 깊이 판정을 사용하려면 양쪽 입력에 동일한 기하 임계값을 사용하는 자동 판정 0.8~0.12 설정과 첫 카메라의 침대 영역이 필요합니다. 법선과 침대 영역의 정확성은 자동 검증하지 않습니다.

품질 수치는 예시일 뿐 검증된 권장값이 아닙니다. 환경별 재투영 오차와 카메라 배치를 측정해 지정합니다.

```bash
python -m bed_pose stereo-evidence --run 그룹_기록_폴더 --calibration 보정.json --output 새_결과_폴더 --depth-check
```

입력 기록과 기존 판정을 검증한 뒤 새 폴더에 결과와 보정 스냅샷·해시를 씁니다. 기록된 그룹의 대상 연결 방식과 수신 시각 게이트, 각 관절의 화면 내 관측을 확인하고 삼각측량합니다. 카메라 뒤쪽, 낮은 시차, 재투영 오차 초과, 관절 미검출은 관절별로 보류합니다. 카메라 간 노출 동기화와 동일인은 자동 검증되지 않으며, 관절 추정이 양쪽에서 비슷하게 잘못되더라도 재투영 검사를 통과할 수 있습니다. 좌표는 보정의 세계 좌표와 단위를 따르는 **추정치**입니다. 실제 환경의 정확도 검증이 필요합니다.

`posture`는 기존 영상 통합 결과, `stereo_posture`는 기존 0.6 기하 규칙의 깊이 후보, `depth_checked_posture`는 두 결과의 일치 여부를 반영한 최종 실험 결과입니다. 각 카메라의 0.8~0.12 프로필에서 같은 기존 기하 임계값을 가져오고, 다르면 실행을 거부합니다. 깊이가 부족할 때 단안 결과로 자동 대체하지 않습니다. 기존 0.6 규칙과 영상 CLIP은 서로 다른 근거이므로 일치 조건은 보류율을 높일 수 있으며 정확도 향상은 아직 검증되지 않았습니다.
