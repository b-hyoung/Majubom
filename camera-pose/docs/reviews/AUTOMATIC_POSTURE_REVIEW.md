## 결론과 범위

현재 기하 규칙은 세 자세의 **실험용 기준선**이며, 신뢰성이 검증된 침대 자세 분류기가 아니다. 기획의 세 라벨·기권·목표/정답/센서 독립성·원본 기록 경계는 유지한다. 작업별 관절 충분성을 일관되게 처리하지 못하는 경로를 수정했지만, 보류를 줄이는 것만으로 정확도가 개선됐다고 판단하지 않는다.

검수 대상은 `automatic_posture.py`, `posture.py`, 공통 좌표 매핑, 실시간 Worker/기록 재검사, 두 시점 결합, 화면의 사유·근거 표시와 관련 테스트다. 저장소 문서와 코드 및 제어한 합성 좌표를 대조했다. 실제 촬영 영상·관절 정답·자세 정답을 새로 확보하지 않았으며 문헌 성능을 재현하거나 검증하지 않았다. 영상 분류기·새 학습·시간 평활화는 추가하지 않았다.

## 확인한 문제와 조치

| 항목 | 재현된 동작과 영향 | 처리 상태 |
|---|---|---|
| 불필요한 하체 의존 | 같은 누움 후보에서 발목이 누락되면 몸통으로 판정하지만, 발목과 무릎의 2D 좌표가 같으면 무릎 각도 계산 실패로 전체 보류 | 0.3에서 수정. 누움 경로는 몸통·얼굴·영역 조건으로 판단하고 계산 불가 하체는 근거에 별도 보존 |
| 부정확한 보류 안내 | 사선 시점의 45° 몸통과 누락 발목을 ‘하체 필요’로 안내. 발목을 복구해도 몸통이 기존 누움/세로 조건에 해당하지 않아 보류 | 0.3에서 ‘촬영 시점 또는 몸통 방향 불확실’로 구분. 자세 판정 범위는 넓히지 않음 |
| 판정 근거 표시 | 새 경로에서는 한쪽 또는 양쪽 무릎 각도가 null일 수 있음. 기존 숫자 전용 표시 함수는 예외 발생 가능 | 숫자만 각도로 표시하고 null은 ‘계산 불가’로 표시. 유효한 하체 정보 부족과 침대 상대 좌표 계산 불가 사유도 한국어로 안내 |
| 이전 결과 재현 | 새 로직을 기존 버전에 덮어쓰면 이전 기록의 재계산 결과가 바뀜 | 0.3을 새 기본값으로 사용하고 0.1·0.2의 기존 판정 경로·모델 ID 의미 유지 |

0.3에서도 앉음·서 있음 구분에 필요한 하체가 누락되거나 투영 각도를 계산할 수 없으면 보류한다. 어깨·골반 누락, 몸통 길이 0, 영역 밖, 얼굴 정보 부족, 앞뒤 모호, 미검출·다인 혼동·추적 보류 게이트는 유지한다. 위 시점의 양쪽 무릎 굽힘 보류와 비수평 몸통/불완전 하체의 보수적 보류도 유지한다. 임계값은 변경하지 않았다.

발목-무릎 좌표 중첩을 실제 인체 이상으로 단정하지 않는다. 가림이나 투영에 의해서도 각도가 정의되지 않을 수 있다. 반대로 하체 계산 실패를 무시해도 몸통이 올바르게 추정됐다는 보장은 없다. 원본 좌표를 지우거나 보간하지 않으며 `quality_status=not_assessed`를 유지한다.

## 남은 위험과 실험이 필요한 가정

| 위험 | 코드/합성 입력에서 확인한 사실 | 판단과 다음 검증 |
|---|---|---|
| 관절 품질 미검증 | 유한한 화면 내 좌표를 사용하며 visibility/presence는 원본에 보존하지만 판정 수용 기준으로 사용하지 않음. 얼굴 세 점을 몸통과 무관한 위치로 옮겨도 바로 누움 후보가 통과함 | 좌표 출력과 올바른 관절을 구분해야 함. 실제 관절 오류·가림 주석으로 품질 정책을 정할 것. 임의 신뢰도 임계값은 추가하지 않음 |
| 폭 비율의 모호함 | 양쪽 어깨끼리, 골반끼리 같은 좌표인 합성 입력도 좁은 폭 조건을 만족해 옆누움으로 출력됨 | 실제 옆누움의 투영과 검출 붕괴가 둘 다 가능하므로 0폭만으로 정답을 단정할 수 없음. 원본 영상과 관절 주석을 함께 확인해야 함 |
| 시점·반전 의존 | 몸통 세로 비율은 영상 축 기준. 같은 합성 형상을 90° 회전하면 사선 모드에서 서 있음 등 보류로 바뀜. 수평 반전하면 앞뒤 판별 부호가 바뀌어 보류됨 | 현 규칙은 회전·반전 불변이 아님. 실제 카메라 방향/미러링을 기록하고 조건별 평가할 것. 부호 검사를 무조건 제거하면 앞뒤 구분 근거도 사라짐 |
| 위 시점의 한계 | 다리가 모두 유효하면 영상 세로 방향도 누움 후보로 허용하지만 하체 부족 시에는 추가 보류. 위 시점만으로 실제 중력·침대 지지 여부를 알아내지 못함 | 보수적 보류를 유지. 서 있음/앉음/웅크림의 혼동과 유효 비율을 실제 영상으로 검증해야 함 |
| 침대 영역의 의미 | 네 점 내부 여부와 골반의 정규화 가장자리 거리를 사용함 | 침대 매트리스 면·두께·시점 오차가 걸터앉음 조건에 영향을 줄 수 있음. 2D 영역 포함은 실제 점유의 정답이 아님 |
| 전환·흔들림 | 현재 프레임만 판정하며 마지막 라벨로 보류를 덮지 않음. 폭 비율 0.22~0.40 사이 등에서 기권함 | 시간 안정화·전환 상태는 기획에 있지만 아직 미구현. 유지/전환 정답과 지연 기준 없이 확인 시간을 임의로 넣지 않음 |
| 두 시점의 공통 실패 | 현재는 시간·대상 게이트 이후 두 자동 라벨이 일치할 때 통합 출력함. 한쪽의 부족 관절을 다른 시점에서 복원하지 않음 | 정답 기반 다중 시점 우월성은 미검증. 양쪽 같은 오답도 가능하며 한쪽 보류로 전체 기권이 늘 수 있음 |

표의 합성 입력은 규칙의 의존성과 실패 가능성을 보여 주는 반례다. 실제 사람에 대한 오분류율·성공률·보류 개선율을 측정한 결과가 아니다. 기하 규칙·학습된 관절 모델·향후 이미지 분류기를 서로 다른 근거로 평가해야 한다.

## 검증 및 남은 작업

전체 169개 개발 검사 통과(78.525초). Chromium의 계산 불가 각도 표시·판정/보류·집계·390px 화면과 JavaScript 오류 없음을 확인했다. 아래 처음 세 항목은 이번 작업에서 실행했으며 실제 자료 평가는 후속이다.

- 누움 경로의 하체 누락/투영 각도 계산 불가, 앉음·서 있음 보류, 중간 몸통 방향 안내, 얼굴/영역/몸통 게이트와 전환 중 기권을 회귀 검사했다.
- 0.1·0.2의 기존 판정, 0.2·0.3의 실제 Worker 기록/재계산, 체크섬을 다시 계산한 후에도 판정 근거 변조를 거부하는지 검사했다.
- 브라우저에서 계산 불가 각도·보류 안내·집계와 작은 화면의 JavaScript 오류를 확인했다.
- 실제 촬영 자료가 확보되면 자세별·가림별·시점/반전별로 올바른 판정, 오분류, 보류를 함께 확인한다. 목표 자세와 실제 확인 정답을 분리한다.

이미지 근거를 쓰는 방식은 기존 모듈형 자세 분류 경로에서 비교할 후보로 유지한다. 이번 검수로 이미지 우선 방식이나 특정 새 모델을 채택하지 않는다. 다음 설계에서는 위 표에서 스켈레톤만으로 해결되지 않는 모호함과 필요한 영상 단서를 연결하고, 같은 정답 자료에서 비교할 조건을 정해야 한다.
