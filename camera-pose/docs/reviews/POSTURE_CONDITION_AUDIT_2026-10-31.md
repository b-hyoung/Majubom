# 자세 판정 조건 검토 · 2026-10-31

이 문서는 코드와 사용 가능한 기록을 대조한 검토다. 실제 정답 주석을 통한 정확도 검증이나 임상적 검증은 아니다. 현재 운영 중인 0.10 규칙·기존 기록은 변경하지 않았다.

## 재현한 문제와 우선순위

1. **걸터앉음의 근거가 부족해도 최종 예측될 수 있음.** 골반만 경계에 가깝고 무릎·발목이 전부 결측인 합성 입력에 앉음 상태를 주면 `edge_sitting`이 나온다. 0.9/0.10에 추가한 다리 경로가 기존 골반 단독 경로를 대체하지 않기 때문이다. 경계 근접이 실제 착석이나 다리 방향을 증명하지 않는다.
2. **영상상 경계와 실제 3D 관계 혼동 가능성.** 침대 네 점의 평면 변환을 몸의 골반·무릎·발목에 적용한다. 이 관절은 침대 면에 있지 않을 수 있으므로 원근·높이·가림 때문에 영상상 밖이 실제 밖을 의미하지 않는다. 골반 양쪽이 경계와 평행해 보이는 특징도 시점과 신체 회전의 영향을 받아 단독 정답이 아니다.
3. **관절 신뢰도의 역할 불일치.** 최종 침대 관계의 점은 화면 안 좌표 여부만 검사한다. 가림에 따른 낮은 visibility 관절이 유효 좌표로 남으면 경계 근거가 될 수 있다. visibility/presence는 모델별 의미가 다르므로 고정 임계값의 신뢰도는 별도 검증해야 한다.
4. **Windows GPU MediaPipe와 CLIP crop 불일치.** 웹 GPU 어댑터 결과의 `presence`는 null이며, `joint-crop-quality-0.1`은 visibility와 presence 모두 0.5 이상을 요구한다. 해당 형태의 합성 관절에서는 사용 가능 관절이 0개로 계산되어 CLIP crop이 보류됐다. 별도 사람 검출 보완 경로가 켜져 유효하다면 동작이 달라질 수 있다. GPU 장치가 표시되는 사실은 CLIP의 각 프레임 추론 성공을 뜻하지 않는다.
5. **누움 판단은 침대 관계·관절 형태와 독립적.** 이는 기존 설계이지만 화면의 누움이 침대 위 정답으로 오해될 수 있다. 영역 밖 사례와 일반 앉음·서 있음·엎드림에 대한 카메라 예측 오차를 별도 측정해야 한다.
6. **두 시점 평균은 상충 제거를 보장하지 않음.** CLIP 점수가 한쪽에 강하게 치우치면 다른 쪽의 반대 근거가 평균에서 사라질 수 있고, 한 시점만 사용한 경우에도 최종 예측이 가능하다. 시간 정렬은 수신 시각 근사이며 노출 동기화가 아니다.

`tests/test_posture_audit.py`의 검사는 현재 제한을 재현한다. 정확도 검사가 아니며 바람직한 최종 규칙을 확정하지 않는다. 기존 합성 자세·기록 재검사 테스트와 별도로 유지한다.

## 현재 기록에서 확인한 범위

2026-10-31 검사 시 `recordings/live`의 완료 기록 5개에서 423프레임을 읽었고 `verified_gt`는 모두 null이었다. 별도 검토 주석은 발견하지 못했다. 이 수치는 확인된 현재 로컬 기록의 범위이며 실제 자세 분포·모델 정확도를 뜻하지 않는다.

사용자가 걸터앉음이라고 설명한 한 기록은 80프레임으로, 당시 저장 예측은 모두 앉음 상태와 침대 안쪽 관계로 걸터앉음이 보류됐다. 0.9/0.10으로 오프라인 재계산하면 73프레임이 걸터앉음이었고 7프레임은 보류됐다. 이 한 사례를 기준으로 조정한 값이므로 독립 검증·재현율·오분류율이 아니다. 당시 여섯 관절의 visibility는 모두 0.5 이상이었으나 정확한 관절 위치의 인증은 아니다.

## 다음 검증과 설계

1. 동일 배치에서 바로 누움·좌우 옆누움·침대 안쪽 앉음·걸터앉음·침대 옆 의자 앉음·서 있음·엎드림·빈 침대·자세 전환을 각기 독립 영상으로 수집한다. 이불·관절 가림·다른 촬영 각도도 구분하고 시각 정렬과 원본 보관 여부를 기록한다.
2. AI 예측과 목표 버튼을 보지 않은 검토자가 실제 자세와 불확실·전환 구간을 별도 주석으로 기록한다. `posture-evaluate`로 클래스별 precision/recall, 범위 밖 오판, 보류 비율을 사람·세션·카메라별로 구분한다. 사람이 다른 참가자와 세션을 시험으로 분리한다.
3. 후보 특징은 골반 중심과 양쪽 골반의 경계 거리·경계 방향 대비 골반 축, 무릎/발목의 같은 경계 쪽 위치, 몸통·허벅지·종아리의 상대 배치와 관절 가시성이다. 침대 면의 2D 호모그래피는 면 밖 신체의 실제 위치가 아니므로 특징마다 영상 좌표임을 명시한다. 같은 특징이 일반 앉음·이불·누움에서 어떻게 나타나는지 먼저 확인한다.
4. 허용오차와 각도는 독립된 개발 자료에서 정하고 별도 참가자 시험 자료에 고정해 평가한다. 필수 관절이 부족하거나 시점별 특징이 충돌하면 보류하는 후보를 비교하되, 실측 없이 기존 운영 문턱을 임의로 올리거나 새 특징을 정답으로 선언하지 않는다.
5. GPU의 presence 누락은 별도 버전의 입력 품질 정책으로 다뤄 CPU/GPU 의미·기록 재검사·대체 검출 경로를 검증한 뒤 적용한다. 0.10 이전 기록의 재현 의미는 바꾸지 않는다.
