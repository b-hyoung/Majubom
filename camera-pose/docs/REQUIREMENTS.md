# 기능 요구사항

[프로젝트 홈](../README.md) · [확정·잠정·보류 사항](DECISIONS.md) · [로드맵](../ROADMAP.md)

**정리일: 2026-10-29 · 목표 요구사항 문서. 구현 상태는 [진행 현황](PROJECT_STATUS.md) 참조**

이 문서는 구현할 기능과 확인 기준을 정리합니다. P0·P1은 개발 우선순위이고, 실제 진행 상태는 [진행 현황](PROJECT_STATUS.md)에서 관리합니다.

## P0 · 핵심 측정과 결과 비교

| ID | 목표 기능 | 확인 기준(초안) |
|---|---|---|
| CORE-01 | 실시간 스켈레톤 추정 | 프레임·시각과 관절 결과를 연결 |
| CORE-02 | 독립 자세 분류 | 목표 자세·외부 센서 결과를 예측 입력으로 사용하지 않음 |
| CORE-03 | 기본 자세 분류 | 바로 누움·옆으로 누움·걸터앉음. 외부 센서와 라벨 매핑 별도 협의 |
| CORE-04 | 변화·이탈·복귀 분석 | 자세 변화·이탈·복귀. 이탈 완료는 내려와 완전히 선 시점; 복귀 운영 해석과 미정 경계는 결정 문서 참조 |
| CORE-05 | 미검출·모호 상태 처리 | 화면에서 사라짐을 이탈로 단정하지 않고 판정 불가 표시 |
| CORE-06 | 시간별 결과 저장 | 실험 ID, 프레임, 예측·이벤트의 시각 관계 보존 |
| CORE-07 | 외부 센서 결과 비교 | 공통 라벨·시각으로 일치·불일치·판정 불가 집계 |
| CORE-08 | 목표 지정과 실제 수행 확인 | 계획 라벨과 확인된 정답을 분리 |
| CORE-09 | 설치 위치·방향의 자유도 | 특정 측면/높이·화면 방향과 수동 시점 선택에 종속되지 않는 판단을 목표로 함. 다양한 실제 시점의 오분류·보류율로 검증; 현재 미달성 |

## P1 · 합의된 운영 기능

| 기능 | 요구 내용 |
|---|---|
| 침대 영역 | 최초 자동 인식 후 유지, 오류/요청 시 자동 재인식, 언제든 즉시 수동 수정 |
| 영역 이력 | 변경 시각과 유효·불확실 구간 기록 |
| 선택적 녹화 | 시작 시 녹화 여부 선택, 분석 중 시작·중지, 여러 녹화 구간 관리 |
| 실시간 화면 | 영상·스켈레톤·자세·침대 경계/점유·이벤트·녹화 상태 확인 |
| 계획 측정 | 단일 자세 및 여러 자세의 순차 측정 |
| 측정 조작 | 자동·수동 전환, 자세별 준비 시간, 준비 완료 입력, 일시정지·재개·재측정 |
| 구간 구분 | 자세 유지와 전환 구간을 구분하고 이탈·복귀 동작도 기록 |

녹화를 꺼도 실시간 분석과 분석 데이터 기록은 계속합니다. 초기 실증은 수동 영역 지정 등 최소 기능부터 시작할 수 있으며, 위 운영 기능은 최종 목표로 유지합니다.

## P2 · 추가 검토

스마트폰 웹 원격 조작·모바일 표시, 사후 정답 수정 UI, 좌·우 등 자세 세분화, 이불 대응, 실사용 환경 확대는 보류 상태입니다. 필요성과 범위를 확인한 뒤 요구사항으로 확정합니다.

## 촬영 조건과 추가 설계 제안 · 2026-10-27

침대·카메라 위치는 세션마다 바뀔 수 있고 세션 중 카메라는 고정합니다. 주변 인물이 등장할 수 있습니다. 한 명 대상 선택·추적, 대상 혼동 시 보류, 카메라 이동 시 영역 재확인은 구현 제안으로 검토합니다. 같은 자세 내 팔다리 움직임 감지는 초기 범위에서 제외합니다.

## 평가 설계 제안

아래 항목은 문헌을 바탕으로 제안한 검증 조건입니다. 확정된 제품 사양과 구분합니다.

| ID | 제안 | 확인할 내용 |
|---|---|---|
| EVAL-01 | 저장 영상·실시간 공통 처리 | 같은 영상·설정으로 비교를 다시 실행 |
| EVAL-02 | 관절 매핑·품질 기록 | 원본 좌표·신뢰도·결측을 보존하고 0 좌표와 구분 |
| EVAL-03 | 자세·침대 위치 병행 | 신체 정규화 후에도 침대 상대 위치 보존 |
| EVAL-04 | 사람·세션 단위 분할 | 인접 프레임·겹치는 시간 창의 분할 간 중복 방지 |
| EVAL-05 | 판정 불가·이벤트 오류 보고 | 유효 구간 성능, 유효 비율, 오경보/시간 병기 |
| EVAL-06 | 시각·설정 추적 | 촬영·수신·처리 시각과 모델·임계값 출처 기록 |

저장 항목과 지표 정의는 [데이터·평가 기준](design/DATA_AND_VALIDATION.md)에 모았습니다.

## 아직 정하지 않은 조건

구체적 촬영 배치, 자세 주석 경계·외부 라벨 매핑, 저장 형식·주기, 준비 시간 기본값, 허용 지연, 정확도 목표, 반복 횟수, 데이터 보관 정책은 미정입니다. 상세 협의 항목은 [결정 사항](DECISIONS.md)을 기준으로 합니다.


## 입력과 화면 추가 요청 · 2026-10-27

사용자는 카메라 선택, 휴대폰/외장/여러 카메라 상황, 촬영 영상 활용과 직관적인 자세 판정 표시를 요청했습니다. 이번 구현은 번호 기반 카메라 선택/확인·파일 선택·독립 입력 탭·상태 카드입니다. 휴대폰의 OS 웹캠 인식, 실제 장치별 지원은 별도 확인합니다. 다중 시점 동기화/융합과 자세 분류기 연결은 후속이며 입력 후보 수를 자세 판정으로 표시하지 않습니다.
