## 현재 동작

기존처럼 `python -m bed_pose live`로 실행하고 침대 영역을 지정한다. 실제 카메라·저장 영상의 기본은 `automatic-posture-rules-0.5`다. 오른쪽에 자세별 적합도, 현재 기준과 최종 라벨을 표시한다.

1. 처리·대상·관절·침대·시점 조건을 확인한다. 미검출·다인 미지정·추적 보류·몸통 부족은 점수로 덮지 않는다. 기존 서 있음 거부와 걸터앉음의 하체/가장자리 조건, 위 시점의 앉음 모호 보류를 유지한다.
2. 현재 관측에서 비교 가능한 자세의 점수를 계산한다. 누움 후보에서는 바로 누움·옆누움을, 기존 걸터앉음 조건에서는 걸터앉음을 평가한다. 걸터앉음 조건이 아닌 누움 프레임에 걸터앉음 점수를 가짜 0으로 부여하지 않고 `null`/‘조건 불충족’으로 구분한다. 모든 자세를 매 프레임 동일한 정보로 평가할 수 있다고 가정하지 않는다.
3. 비교 가능한 점수 중 최고점을 고른다. 기준 **0.65 이상**이면 출력한다. 미만이면 보류한다. 이는 구현 초기 실험값으로, 실제 영상으로 보정한 기준이 아니다.
4. 1·2위 차이가 **0.10 미만**이면 ‘두 자세의 점수가 비슷함’을 표시하되 **판정은 계속한다**. 0.74와 0.72라면 0.74 자세를 출력한다. 수치상 동점(차이 ≤ 1e-12)만 방향을 고를 근거가 없으므로 보류한다. 이전 라벨을 임의로 유지하지 않는다.

점수는 **자세별 독립적인 규칙 적합도**이며 확률·정확도·가중치 자체가 아니다. 점수 합계를 1로 정규화하지 않는다. 따라서 두 자세가 동시에 높은 점수를 가질 수 있다. 가중치는 근거를 섞는 비중이고, 최종 점수와 구분한다.

## 점수 계산

몸통 기준 어깨·골반 수직 폭 비율을 사용한다. 옆누움의 기준점은 기존 0.22, 바로 누움은 0.40이다. 두 기준 사이 간격을 d라 할 때 기준에서 반대 방향으로 멀어질수록 적합도가 선형으로 줄고, 거리 2d에서 0이 된다. 기준보다 더 해당 방향이면 1로 제한한다. 이 겹치는 구간으로 단순 조건 통과/실패를 연속 점수로 바꾼다.

예를 들어 두 폭이 모두 0.30이면 2D 옆누움 약 0.778, 바로 누움 약 0.722다. 3D가 없고 다른 조건을 통과하면 옆누움을 출력하면서 가까운 점수라는 안내를 표시한다. 이 계산 예는 코드의 산술 설명이며 실제 사람 인식 성능 수치가 아니다.

| 파라미터 | 초기값 | 역할 |
|---|---|---|
| `score_min` | 0.65 | 최고 적합도의 판정 기준 |
| `score_close_gap` | 0.10 | 가까운 점수 안내 기준. 기권 조건 아님 |
| `score_overlap_scale` | 2 | 기준 사이 간격에 대한 선형 지지 구간 배수 |
| `score_shoulder_weight` / `score_hip_weight` | 0.5 / 0.5 | 어깨·골반 적합도 결합 비중 |
| `score_2d_weight` / `score_3d_weight` | 0.6 / 0.4 | 가용한 2D·추정 3D 적합도 결합 비중 |
| `score_sitting_torso_weight` | 0.35 | 걸터앉음의 세로 몸통 적합도 비중 |
| `score_sitting_knee_weight` | 0.45 | 양쪽 무릎 굽힘 적합도 비중 |
| `score_sitting_edge_weight` | 0.20 | 침대 가장자리 근접 적합도 비중 |
| `score_knee_peak` | 90° | 무릎 굽힘 적합도 1의 기준. 기존 굽힘 범위 끝에서 0 |

3D는 같은 후보의 모델 추정 어깨·골반 깊이 성분으로, 기존 앞면 기준 0.35·옆면 기준 0.75 사이에서도 연속 적합도를 만든다. 어깨·골반의 부호 있는 깊이 차이가 크게 다르거나 3D 몸통 일관성 조건을 통과하지 못하면 이 근거는 제외한다. **3D가 없으면 2D만으로 가중치를 다시 정규화**하며 결측을 낮은 점수 0으로 넣지 않는다.

2D 몸통 축 교차·과도한 어긋남·어깨와 골반의 상반된 강한 투영은 기존처럼 보류한다. 바로 누움에는 얼굴·해부학적 앞뒤 단서도 필요하다. 0.4와 달리 **일관된 2D와 3D가 서로 다른 방향을 지지한다는 이유만으로는 보류하지 않고**, 가중 합계와 최소 기준으로 결정하며 충돌을 참고 안내로 남긴다. 추정 3D의 비중이 언제나 더 신뢰할 만하다고 가정하지 않는다.

걸터앉음은 기존 필수 조건을 통과한 경우 세로 몸통, 양쪽 중 낮은 무릎 굽힘 적합도, 가장자리 근접도를 위 비중으로 결합한다. 현재 누움/앉음의 **진입 조건 자체는 점수화로 제거하지 않았다.** 촬영 시점·몸통 방향 불확실 보류는 남을 수 있다.

모든 초기값·가중치는 실제 자료에서 학습하거나 논문으로 검증한 수치가 아니다. 프로필과 모델 ID 해시에 남겨 실험별로 추적한다. threshold 변경이나 점수 출력을 실제 정확도 향상으로 해석하지 않는다.

## 기록·검사·이전 버전

`rule_features.score_decision`에 자세별 점수/비교 불가 사유·근거별 점수·최고 후보·2위·점수 차이·최소 기준·가까움 안내·최종 결과를 기록한다. `margin_required=false`이며 별도 1·2위 차이 기권 조건은 없다. 원본 2D·추정 3D, 목표/실제 정답/외부 센서 분리는 유지한다.

`live-inspect`는 원본 관절과 당시 프로필에서 점수·결정을 재계산한다. **0.1~0.4는 이전 필드·규칙으로 재현하며 새 가중치를 소급 적용하지 않는다.** `posture-evidence` 보고서 0.3은 자세별 점수·기준·점수 차이·가까움 여부를 CSV에 추가하고, 이전 기록의 해당 칸은 빈칸으로 유지한다.

높은 점수라도 지원 범위 밖 자세를 반드시 거부한다고 보장하지 않는다. 실제 영상의 클래스별 오분류·보류율, 카메라 시점·가림·전환에 대한 검증은 남아 있다. 가까운 점수에서도 1위를 고르면 판정 범위는 넓어질 수 있지만 오분류와 프레임별 흔들림도 늘 수 있다. 다음은 별도 실제 정답이 있는 영상에서 이전 0.4와 0.5를 같은 조건으로 비교해 초기값을 조정하는 작업이다.
