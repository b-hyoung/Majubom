# 순간 판정과 시간적 안정화

[진행 현황](../PROJECT_STATUS.md) · [두 카메라 구조](MULTI_CAMERA_DESIGN.md) · [사람 입력 영역](PERSON_CROP.md)

**2026-10-31 · 실험 구현, 실제 영상 성능 미검증.** 기존 `posture_assessment`와 자세 점수·임계값·원본 라벨은 바꾸지 않습니다. `stable_posture`가 별도의 과거/현재 관측을 이용해 자세를 확인합니다. 새 AI 모델·미래 프레임·침대 이탈 이벤트는 추가하지 않습니다.

신규 입력의 `posture-stability-0.2`는 `supine`과 방향 미확인 `lying`을 같은 `lying` 상태로 확인합니다. 원본 순간 라벨은 보존합니다. 이전 `posture-stability-0.1` 기록은 기존 구분을 유지해 재검증합니다. 화면의 통합 명칭은 누움입니다.

## 설정과 의미

입력 추가 창의 **자세 안정화 설정**에서 조절합니다. 연결된 입력의 설정을 바꾸려면 입력을 다시 연결합니다. 일반 실행 명령은 같습니다.

| 설정 | 초기값 | 의미 |
|---|---|---|
| 확인 시간 | 500ms | 같은 순간 라벨의 연속 관측 구간에 필요한 최소 시간 |
| 최소 관측 수 | 3개 | 확인 시간과 함께 만족해야 하는 서로 다른 관측 수 |
| 허용 관측 간격 | 1000ms | 이 간격을 초과하면 앞의 근거를 버리고 다시 확인 |
| 입력 만료 시간 | 1500ms | 새 카메라 관측이 없으면 현재 안정 라벨 표시를 만료 |

`posture-stability-0.1/0.2`에 모든 설정과 `future_frames=false`, `hold_policy=clear_current_and_pending`를 저장합니다. 모두 미검증 초기값입니다. 확인 시간은 0–10000ms, 최소 관측은 2–100개, 관측 간격은 1ms 이상이며 간격 ≤ 만료 시간 ≤ 60000ms를 검사합니다. 확인 지연은 FPS·누락·보류에 따라 확인 시간보다 길어질 수 있습니다.

## 상태 전이

- **확인 중(confirming):** 같은 유효 라벨이 설정 시간과 횟수를 모두 만족하기 전. 현재 안정 라벨은 없음.
- **안정(stable):** 위 조건을 만족한 라벨을 출력. 같은 라벨의 새 관측으로 유지할 수 있음. 실제 정답이나 확률 보정의 의미는 아님.
- **전환 확인 중(changing):** 기존 안정 라벨과 다른 후보를 확인 중. 현재 `label`은 null이고 이전 값은 `last_confirmed_label`에 과거 이력으로만 보존. 후보가 기존 라벨로 돌아오면 기존 안정 상태를 재개할 수 있음.
- **보류(held):** 순간 결과가 보류/미사용/범위 밖이면 현재·후보 근거를 즉시 비움. 이후 다시 확인해야 함. 보류를 숨기기 위해 과거 라벨을 유지하지 않음.
- **만료(expired):** 카메라 입력 중단·종료·오류에서는 표시 라벨을 제거. 원래 기록에 가짜 새 프레임을 추가하지 않는 읽기 전용 표시 투영임.
- **새 통합 관측 대기(waiting_for_pair):** 양쪽의 새 관측을 확보하기 전 결과가 달라졌을 때 현재 안정 라벨을 보류. 같은 결과의 한 시점 갱신만으로 확인 횟수를 늘리지는 않음.

대상/트랙·분류기·침대 영역 개정·시계가 바뀌거나 관측 간격이 초과하면 근거를 초기화합니다. 같은 프레임의 반복 조회는 누적하지 않습니다. 두 카메라는 기여 시점 구성이 달라져도 초기화하며 시간·대상 게이트를 완화하지 않습니다. 현재 대상 추적 자체는 잠정적이며 자동 동일인 검증을 제공하는 것은 아닙니다.

## 시간축·단일/두 카메라

`posture_stability.py`는 영상·모델에 독립된 인과적 상태 머신입니다. 단일 입력은 분석된 매 프레임에서 호출합니다. 카메라는 수신 시각, 저장 영상은 상대 PTS를 사용합니다. 영상 처리 속도가 느려지거나 일시정지해도 벽시계 대기 시간을 자세 유지 근거로 누적하지 않습니다. 저장 영상의 정지 화면은 과거 영상으로 열람할 수 있지만 종료된 입력을 현재 라이브 자세로 표시하지 않습니다.

단일 측정 시작 때 초기화하며 manifest 설정으로 첫 기록 프레임부터 재계산할 수 있습니다. 미리보기에서 얻은 누적 근거를 측정 초기에 몰래 가져오지 않습니다.

두 카메라의 라이브 안정화는 서버 처리 주기에서 양쪽 프레임이 새로워진 최신 관측 쌍만 사용합니다. HTTP 조회는 누적을 수행하지 않습니다. 저장된 그룹 안정화는 종료 후 정렬된 **FIFO 관측 쌍 전체**를 순서대로 사용합니다. 라이브와 저장 결과는 샘플링 시점/수에 차이가 있으므로 동일 출력이라고 보증하지 않고 `sampling=live_distinct_latest_pairs` / `saved_fifo_pairs`를 구분합니다. 양쪽 설정은 확인 시간·최소 횟수의 최댓값, 허용 간격·만료 시간의 최솟값으로 병합해 그룹 manifest에 명시합니다.

`time_ns`와 `confirmed_ns`는 해당 근거 프레임의 시간축입니다. 실제 자세 전환 시각이나 노출 시각·처리 완료 시각이 아닙니다. `confirmation_delay_ms`는 첫 연속 후보 관측부터 확정 근거 프레임까지의 지연이며, 실제 신체 전환 감지 지연과 구분합니다. 별도 정답 주석이 없으므로 후자는 측정하지 않았습니다.

## 화면·기록과 검증

기존 순간 판정 아래 **안정된 자세**를 별도로 표시합니다. 프레임/통합 관측 번호·후보·확인 횟수·설정과 관측 기준 확인 지연을 함께 표시합니다. 입력 중단 시 만료하며 서버 연결이 끊긴 경우도 현재 라벨로 남기지 않습니다. 기록 표는 순간/안정 결과를 분리하고 과거 형식에는 ‘당시 기록 없음’을 표시합니다.

개별 `live_frames.jsonl`과 그룹 `posture_predictions.jsonl`에 `stable_posture`, manifest에 `stability_profile`을 저장합니다. 원본 관측 순서와 설정으로 재계산해 변조/누락을 검사합니다. 이전 기록에 안정화 결과를 새로 만들어 넣지 않습니다. 기존 CSV·정답 평가·시간축의 순간 판정 의미는 유지하며, 안정화 성능/실제 전환 지연 비교는 후속입니다.

목표 자세·외부 센서·정답을 안정화 입력으로 사용하지 않습니다. 원본 자세와 안정 결과를 센서 비교에서 혼용하거나 안정 결과를 정답으로 삼지 않습니다. 상태 변경은 임상적 자세 변화·침대 이탈/복귀 이벤트 구현과 다릅니다.

검증은 지정 라벨/생성 영상으로 확인·전환·보류·중복·대상/시계 변경·간격 초과·입력 만료·PTS·그룹 쌍·재해시 변조 거부를 확인하는 개발 검사입니다. 실제 영상의 오분류/보류·자세 전환 지연 개선은 아직 미검증입니다.
