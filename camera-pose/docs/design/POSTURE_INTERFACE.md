# 자세 판정 인터페이스

[문서 목차](../README.md) · [분야 목차](README.md) · [현재 상태](../PROJECT_STATUS.md)

**기준일: 2026-10-29.** 최초 인터페이스 도입과 분류기 미연결 단계는 [과거 기록](https://github.com/zntks1234/bed-pose-skeleton-ai/blob/98b1529bfea26f4679f9b19d3744d5c4f122d0da/docs/archive/POSTURE_INTERFACE_BEFORE_REORGANIZATION.md)입니다. 현재 실제 카메라/파일 입력은 기본 자동 규칙 0.5를 사용합니다.

## 입력과 출력

`posture.py`의 `PostureInput`은 선택한 후보의 유효한 공통 2D 관절, 영상 크기, 침대 영역과 선택적 같은 후보의 추정 `world_body`를 전달합니다. 목표·정답·외부 센서·파일명은 분류 입력에 넣지 않습니다. `PostureClassifier.predict`는 `supine`/`side`/`edge_sitting` 또는 None을 반환하는 확장 지점입니다.

`assess_frame`은 처리 상태·대상·좌표 가용성·분류기 결과를 모아 프레임 ID·시각·status/label·사유·근거를 구성합니다. 동작 원리는 [현재 규칙과 점수](WEIGHTED_POSTURE.md)를 따릅니다. 기본 합성 데모는 실제 사람 분류기가 아니며 자동 판정이 꺼져 있습니다.

## 대상과 품질 경계

- 추적이 설정되면 해당 후보를 사용하고, 추적 보류 시 다른 후보로 바꾸지 않습니다.
- 추적 미설정의 단일 출력 후보는 잠정 관측입니다. 실제 화면에 한 명만 있다는 보장이 아닙니다.
- 후보 없음·복수 후보 미지정·처리 실패·유효 좌표 부족은 보류 사유로 구분합니다.
- 좌표는 가용성·유한성·화면 내부 여부를 확인합니다. 실제 관절 정확도를 보장하지 않습니다.
- 이전 기록은 당시 버전의 규칙으로 재계산합니다. 새 판정으로 원본 결과를 덮어쓰지 않습니다.

## 화면·기록·두 시점

단일 화면은 표시 영상과 같은 프레임의 저장/현재 판정 근거를 묶어 표시합니다. 입력 종료·오류·모델 변경 중 이전 자세를 새 관측처럼 보이지 않도록 상태를 구분합니다. 미리보기 처리 방식은 [동시 처리 계약](PREVIEW_CONCURRENCY.md)을 따릅니다.

두 카메라의 자동 결합은 운영자 동일인 확인·잠정 추적·수신 시각 조건과 양쪽 라벨 일치를 사용합니다. 촬영 동기화·품질 보완 결합과 구분합니다. 자세·스켈레톤·실루엣 정확도와 실사용 효과는 실제 정답 자료로 별도 검증해야 합니다.
