**기준일: 2026-10-27 · 운영 절차 초안**

자유 분석과 단일·순차 계획 측정을 지원하는 방향입니다. 실제 자세 순서, 유지 시간, 반복 횟수와 센서 동시 측정 방법은 아직 확정하지 않았습니다.

## 측정 모드

| 모드 | 사용 방식 | 기록할 구간 |
|---|---|---|
| 자유 분석 | 정해진 자세 순서 없이 분석 | 연속 예측·상태·이벤트 |
| 단일 계획 | 하나의 목표 자세를 준비하고 반복 측정 | 목표·준비·측정·반복 회차 |
| 순차 계획 | 여러 자세·동작을 등록해 순서대로 측정 | 단계별 목표·준비·전환·측정 |

계획 측정에서는 **자세별 준비 시간을 개별 설정하는 방식과 준비 완료 입력을 모두 지원**합니다. 자동·수동 진행을 전환하고 일시정지·재개·단계 재측정을 할 수 있도록 설계합니다.

## 공통 절차

1. **실험 준비:** 세션 ID·촬영 조건을 기록하고 원본 영상 녹화 여부를 선택합니다.
2. **시야 확인:** 카메라와 침대 영역을 확인합니다. 필요하면 재인식·수동 보정을 합니다.
3. **시간 기준 확인:** 센서와 동시 측정할 경우 시계·측정 시각의 의미를 확인합니다.
4. **모드 선택:** 자유 분석 또는 단일·순차 계획을 시작합니다.
5. **분석·기록:** 준비·전환·유지/동작 측정 구간을 구분해 결과를 기록합니다.
6. **수행 확인:** 실제 자세와 이벤트 시각을 관찰 또는 영상으로 확인하고 검증 상태를 남깁니다.
7. **종료·검토:** 녹화 구간, 결측, 불확실 구간, 재측정 필요 사례를 확인합니다.

녹화는 분석 중에도 시작·중지할 수 있습니다. 녹화하지 않는 동안에도 분석 결과 기록은 계속합니다.

## 세션별 준비와 이벤트 사례 · 2026-10-27

**합의:** 초기 자세는 바로 누움·옆으로 누움·걸터앉음이며 움직임은 이들 사이의 변화와 이탈·복귀입니다. 설치는 세션마다 달라질 수 있지만 세션 중 카메라는 고정합니다. 주변 인물이 나타날 수 있습니다.

**운영 제안:** 시작 시 침대 영역·누운 대상·침대 가장자리·이탈 후 완전히 선 모습의 관찰 가능성을 확인하고 배치를 기록합니다. 측정 대상 한 명을 선택하고 혼동 시 보류·재선택합니다. 카메라 이동 시 침대 관계가 필요한 판정을 보류하고 영역을 재확인합니다. 구체적 자동화·복구 방법은 미정입니다.

| 관찰 상황 | 판정 설계 제안 |
|---|---|
| 걸터앉아 발만 바닥에 둠 | 이탈 완료 전 |
| 일어나다 다시 앉음 | 이탈 완료 이벤트 없음 |
| 내려와 완전히 섬 | 합의한 이탈 완료 조건; 품질·시간 확인 후 한 번 기록 |
| 침대 밖에 계속 서 있음 | 이벤트 반복 생성 없음 |
| 다시 걸터앉음 | 복귀 운영 해석에 해당; 세부 경계 검토 필요 |
| 바로 침대에 올라가 누움 | 복귀에 포함하는 제안; 세부 경계 검토 필요 |
| 측정 시작 때 이미 침대 밖임 | 초기 상태만 기록 |
| 가림·대상 혼동·관측 공백 | 판정 보류, 미확인 이벤트를 소급 생성하지 않음 |

이 사례는 구현·실험 결과가 아닙니다. 복귀 해석의 대화 근거는 [결정 사항](../DECISIONS.md), 자세 안정화·보류 방식은 [시스템 구조](ARCHITECTURE.md)를 따릅니다.

## 계획 측정의 구간

| 구간 | 의미 | 평가 처리 |
|---|---|---|
| 준비 | 참가자가 목표 수행을 준비 | 유지 자세 평가에서 제외할 수 있음 |
| 전환 | 자세 변경·몸 일으킴·이탈·복귀 동작 | 이벤트 평가 대상이면 시각과 동작을 보존 |
| 유지·동작 측정 | 정한 목표를 실제 수행 | 실제 확인 라벨과 예측을 별도 저장 |
| 다음 단계·재시도 | 다음 목표로 이동하거나 반복 | 단계 ID와 조작 시각으로 구분 |

버튼 시각은 사용자의 조작 시각입니다. 실제 동작 시작·완료 시각과 같다고 가정하지 않습니다. 특히 이탈·복귀 전환을 단순 준비 구간으로 제외하지 않습니다.

## 실제 정답 확인

| 조건 | 확인 방법 | 남길 상태 |
|---|---|---|
| 관찰자 있음 | 실시간 입력 후 필요 시 검토 | 임시 기록 또는 검증 완료 |
| 관찰자 없음·녹화 있음 | 영상에서 사후 확인 | 확인 전에는 미확인 |
| 관찰자 없음·녹화 없음 | 실제 수행을 확인할 근거가 부족할 수 있음 | 계획 라벨과 정답 미확인을 구분 |

목표 자세, 카메라 예측, 센서 결과, 실제 정답은 각각 저장합니다. 계획이나 AI 예측을 정답으로 자동 전환하지 않습니다. 가능하면 검토자는 예측 결과를 보기 전에 실제 수행을 판단하고, 애매한 구간은 불확실로 남깁니다.

## 비교 영상에 포함할 상황 — 제안

| 목적 | 상황 | 핵심 기록 |
|---|---|---|
| 기본 자세 | 바로 누움·옆누움·걸터앉음 | 실제 자세, 관절 품질 |
| 이탈 구분 | 몸만 일으키고 다시 눕기·앉은 채 유지·실제 이탈 | 전환 시작·완료, 침대 관계 |
| 복귀 | 침대 밖 유지 후 돌아와 앉기/눕기 | 이탈 상태와 복귀 시점 |
| 인식 실패 구분 | 화각 경계·일시 가림·관절 추정 실패 | 실제 위치, 실패 원인·길이 |
| 후속 가림 시험 | 가림 없음·부분 가림·이불 | 입력·가림 조건별 별도 결과 |

후속 가림 시험은 초기 필수 범위가 아닙니다. 같은 저장 영상의 모델 비교와 실제 카메라 입력의 전송·처리 지연 시험을 구분합니다.

## 실험 전에 정할 것

준비 시간 기본값, 측정 종료 규칙, 반복 횟수, 시계 정렬, 이벤트 허용 오차, 정답 확인 담당, 촬영 동의·보관 방식을 정해야 합니다. 스마트폰 원격 조작과 사후 라벨 수정 UI는 [보류 사항](../DECISIONS.md)으로 유지합니다.

관련 자료는 [BedEye P03](../research/BED_POSTURE_PAPERS.md#p03), [BlanketSet P14](../research/BED_POSTURE_PAPERS.md#p14)입니다. [P11](../research/BED_POSTURE_PAPERS.md#p11)·[P12](../research/BED_POSTURE_PAPERS.md#p12)는 본문 미확보이므로 구체적 실험 조건의 근거로 사용하지 않습니다.

## 현재 실행 가능한 최소 경로

[실시간 측정기](../guides/LIVE_MEASUREMENT.md)는 자유 측정의 영상 확인→수동 침대 사각 영역→측정 시작/종료→관절/시각/영역 이력 기록을 연결한 초기 구현입니다. 현재 영상 녹화는 꺼져 있고 기능이 없으며, 두 입력 그룹의 단일 목표·준비 타이머/준비 완료·자동/수동 종료는 [단일 계획 측정](../guides/SINGLE_POSTURE_PLAN.md)에 연결했습니다. 단일 입력 계획·순차 진행·실제 자세/이벤트 확인·센서 동시 측정은 미구현입니다. 위 공통 절차 전체가 구현됐다고 해석하지 않습니다.
