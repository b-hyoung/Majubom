# 표본 증강(Data Augmentation) 정리 — 2026-07-06

> 목적: 이미 수집한 보행/자세/이탈 테스트 데이터를 증강 알고리즘으로 표본 확대.
> 결론 먼저: **"증강=무조건 이득"이 아니다. 도메인에 맞는 증강만 효과** — A/B로 실측 검증함.

## 대상 데이터
| 데이터 | 규모 | 특성 |
|---|---|---|
| mmWave 이탈 시퀀스 (`seq_dataset.jsonl.gz`) | 569 시퀀스 (30프레임×64점×[x,y,z,dop]) | 클래스 불균형 (empty 306 / side_left 24) · 임박(Y=1) 55 |
| TOF 자세 (`../../TOF/dataset/*.jsonl`) | 클래스당 ~1500 짝지음 (32차원 거리) | 한 사람·한 세션 |

## 만든 스크립트 (전부 센서 없이 오프라인)
| 파일 | 역할 |
|---|---|
| `augment_seq.py` | 이탈 시퀀스 증강. **기본=타임워프+지터** (회전/스케일은 `--rigid`로만) |
| `analyze_aug.py` | 증강 전/후 F1 정직 비교 (train만 증강, test 원본, 5시드 평균) |
| `../../TOF/ml/augment_tof.py` | 자세 거리벡터 노이즈 지터 + 존 드롭아웃 (`-1` 보존) |

## A/B 실측 결과 (이탈 임박 예측, LSTM, 5시드 평균)
```
train 184(임박 27) / test 79(임박 28)   베이스라인(다수예측) 64.6%

증강 X (baseline)        F1=39.6±12.4   recall 32%
증강 O 회전+스케일 1:1     F1=32.2±10.8   recall 23%   ← 손해 (-7)
증강 O 기하안전 1:1        F1=44.9±11.2   recall 38%   ← 이득 (+5.3)
증강 O 기하안전 0.5배      F1=41.0±12.3   recall 34%
```

## 핵심 발견
- **회전/스케일 증강은 이 시스템에 독.** 센서·침대가 **고정**이라 yaw 회전/스케일은
  물리적으로 불가능한 배치를 만들어 label-불일치 샘플을 주입 → F1 −7.
- **타임워프(이탈 동작 속도 변주)가 최다 기여.** 실제로 새로운 시간패턴을 만들어 일반화 ↑.
- 프레임 특징이 median이라 점 지터는 대부분 흡수 → 지터 단독 효과는 작음.

## 정직 장치 / 한계
- 증강분에 `"aug": true` 태그 → **train 전용, test 오염 금지** (안 그러면 점수만 부풂).
- 증강은 **노이즈 강건성 + 클래스 균형**만 올림. **다른 환자 일반화는 못 만듦** —
  한 사람·한 세션이라는 근본 한계는 **실데이터(다인·다세션) 수집**으로만 해소.
- test 표본 28개 → F1 ±11 노이즈. 향상은 긍정적 신호이나 통계적으로 강하진 않음.

## 2026-09-14 재검토 — GRU 비교 + 신규 증강기법 (`analyze_v2.py`, 원본 스크립트는 그대로 보존)

문헌 조사(2026-09) 결과를 같은 태스크·같은 5시드 프로토콜로 직접 재보았다.

1. **동일 스크립트(`analyze_aug.py`, 코드 수정 없음)를 오늘 재실행하니 무증강 기준값이
   위 표(F1 39.6±12.4)와 다르게 나왔다** (오늘: F1 48.7±14.0, torch 2.12.1 환경).
   코드를 안 바꿔도 이만큼 흔들린다는 뜻 — 반대로 증강을 적용한 조건은 훨씬 안정적으로
   재현됐다(기하안전 1:1: F1 44.9±11.2 → 44.9±14.1, 소수점까지 거의 동일). 표본이 늘수록
   (157개 vs 27개) 재현성도 오른다는 간접 증거. **결론 불변**: test 28개짜리 평가로
   "증강이 이득"이라 확정할 수 없다 — 재현성 자체가 그 근거를 보강한다.

2. **LSTM → GRU 비교(무증강 기준)**: acc 71.1±5.5→73.2±2.6, F1 48.7±14.0→50.4±13.4,
   recall 41%→41%(동률), 파라미터 3,026→2,282(-25%). 모든 지표 동률 이상 + 정확도 분산
   대폭 감소. 근거: Sykes, Maghsoudimehrabani & Al-Shanoon (2026), "Benchmarking
   Time-Series AI Architectures for Wearable Sensor-Based Fall Prediction", Sensors
   26(11):3326 — 유사한 소수클래스·이벤트임박예측 벤치마크에서 경보 임계값 운용 시 GRU가
   LSTM/Transformer보다 실제 이벤트를 더 많이 잡았다는 결과와 방향이 일치.
   **단, GRU+증강 조합은 오히려 크게 나빠짐**(기하안전 1:1 F1 33.0±11.6, recall 30%) —
   "GRU가 항상 낫다"가 아니라 "GRU+무증강 조합이 지금까지 시도한 6가지 조합 중 최고"가
   정확한 결론.

3. **신규 증강(window-slice / window-warp)**을 기존 기하안전(지터+타임워프)에 추가
   — 근거: Iwana & Uchida (2021), "An Empirical Survey of Data Augmentation for Time
   Series Classification with Neural Networks", PLOS ONE 16(7):e0254841(128개 UCR
   데이터셋 실측에서 이 두 기법의 평균 순위가 가장 높았고, 작은 데이터셋일수록 증강
   효과가 크다고 보고). LSTM 기준 F1 44.9±14.1→46.8±11.1, recall 41%→44%, 분산도 감소.
   방향은 논문과 일치하나 여전히 무증강 평균(48.7)보다는 낮아 "확정적 향상"이라 부르긴
   이르다.

**결론**: 아키텍처(GRU)·증강기법(window-slice/warp) 둘 다 문헌이 권고하는 방향과
일치하는 근소한 개선 신호는 보이지만, 이 데이터 규모(test 28개)에서는 어느 것도
통계적으로 확정할 수 없다. 근본 병목은 여전히 데이터양이다 — 이 결론은 2026-07
기록과 같고, 이번엔 아키텍처 변경까지 재확인했다는 점만 다르다.
