# ⚠️ mmWave 환자 추적·낙상 위험 예외 케이스 분석 (2026-07-03)

> 대상 코드: [send_mmw.py](send_mmw.py) `select_patient()` / [../server/mmw_logic.py](../server/mmw_logic.py) `evaluate()`
> 목적: "여러 사람 중 환자만 골라 gait baseline 누적 + 낙상 감지" 로직의 **아직 안 막은 구멍** 정리.
> 상태: **미구현(알려진 한계)**. 실측·후속 작업에서 우선순위대로 대응.

---

## 현재 방어선 (이미 구현됨)

1. **침대 소속도(bed affinity)** — track별 최근 60초 이력 중 침대존(`X[-1.3,1.1] Y[1.0,3.6]`) 안에 머문 비율. 순간 위치가 아니라 이력으로 "환자다움"을 판정.
2. **walking 게이트** — 실제 보행(속도≥`WALK_SPEED_MIN`, 순이동≥`WALK_DISP_MIN`)일 때만 baseline 반영. 정지/누움 값으로 baseline 오염 방지.
3. **애매하면 보류** — 침대 소속 후보(aff≥`AFFINITY_MIN`=0.25)가 정확히 1명일 때만 확정. 0명 또는 2명+면 `lock=False`로 보류.

아래는 **이 3중 방어선으로도 아직 못 막는** 케이스들.

---

## 🔴 미탐지 — 낙상을 못 잡는 경우 (최우선)

### #1 낙상 순간 track이 끊기면 낙상 자체를 놓침
- `height_drop = max(z) - min(z)`는 track이 낙상 내내 유지돼야 계산됨.
- 사람이 쓰러지면 RCS 급감/바닥 밀착으로 **track이 죽는 경우가 많음** → 샘플 끊김 → `n_targets=0` → 보류.
- **결과: 진짜 낙상인데 "아무도 없음"으로 조용히 넘어감.**
- 완화: "존 안에 있던 track이 갑자기 소멸 + 마지막 z 하강" → 낙상 의심 알람.

### #2 천천히 주저앉는 낙상은 임계 미달
- `HEIGHT_DROP_FALL=1.2`m를 한 윈도우(10초)에 넘어야 함.
- 노인성 "스르륵 미끄러짐 / long-lie"는 느려서 미탐지.
- 완화: 절대임계 외 "바닥 근처 z 지속 + 무동작"(주저앉아 못 일어남) 상태 감지.

### #3 여러 명일 때 낙상 감시가 track 1개뿐
- raw(=height_drop)는 `main_tid` 하나만 계산.
- 2명 있을 때 환자가 아닌 쪽(또는 non-main)이 쓰러지면 안 보임.
- 완화: 낙상(z 급강하)만은 **모든 alive track**에 대해 검사.

## 🟠 거짓 알람 — 알람 피로 → 무시 → 위험

### #4 sway / speed_cv 수식이 특정 보행에서 폭발
- `speed_cv = std/mean` → 느린 셔플링(mean 작음)에서 값 폭증 → 거짓 z.
- `sway`는 시작-끝 직선축 기준 → 방향 전환/제자리 배회(loop) 시 축이 애매해져 왜곡.
- 완화: 최소 속도/직선성 조건 미달 윈도우는 baseline·알람에서 제외.

### #5 고스트(유리문·금속) 병합 스파이크
- X≈−2.25 반사가 환자 track에 섞이면 speed/sway 순간 폭증 → 거짓 warning.
- 완화: cfg `staticBoundaryBox`로 반사영역 컷 + 물리적으로 불가능한 순간속도 필터.

---

## 🟡 baseline 오염 / 정체

### #6 평생 누적 baseline → 서서히 나빠지면 "새 정상"이 됨 (삶은 개구리) ⚠️
- `update_baseline`은 sum/sumsq를 **평생 누적**, 감쇠·윈도우 없음. n이 커질수록 새 데이터가 희석됨.
- 환자가 점진적으로 악화되면 그 악화가 천천히 baseline에 흡수돼 **알람이 안 뜸**.
- 낙상위험 "예측"의 핵심(점진적 악화 포착)을 정면으로 놓침.
- 완화: 최근 N일 슬라이딩 윈도우 baseline, 또는 지수감쇠(EWMA).

---

## 🔵 환자 정체성 구멍 (baseline 오염원)

### #7 `n==1 → 무조건 환자` 가정이 뚫림 ⚠️
- 환자 외출 중 **청소부/간호사 혼자** 방에서 걸으면 → `n=1 lock=True` → 그 사람 보행이 환자 baseline에 들어감.
- 두 명이 붙어 걸으면 tracker가 1개로 **병합** → `n=1` → 역시 lock → 뒤섞인 보행 누적.
- 완화: `n==1`이어도 그 track의 침대 소속 이력이 전무하면 baseline 반영 보류(복귀 초기 딜레마는 튜닝 필요).

### #8 환자가 침대 대신 의자 선호 → 앵커가 틀림
- 환자가 주로 의자에 앉으면 침대 소속도 0 → 다인 상황에서 영영 특정 안 됨.
- 완화: "환자 상주 구역"을 침대∪의자로 확장, 또는 수동 지정.

## 🟣 환경 / 센서

### #9 폴에 얹은 센서가 흔들리거나 밀리면 좌표계 전체 무효
- 침대존이 실좌표와 어긋나 모든 판별이 **조용히 오작동**. 감지 수단 없음.
- 완화: 정적 참조점(벽/침대 프레임) 위치 상시 모니터 → 벗어나면 "재캘리브 필요" 경고.
