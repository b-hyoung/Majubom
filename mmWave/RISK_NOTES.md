# ⚠️ mmWave 환자 추적·낙상 위험 예외 케이스 분석 (2026-07-03)

> 대상 코드: [send_mmw.py](send_mmw.py) `select_patient()` / [../server/mmw_logic.py](../server/mmw_logic.py) `evaluate()`
> 목적: "여러 사람 중 환자만 골라 gait baseline 누적 + 낙상 감지" 로직의 **아직 안 막은 구멍** 정리.
> 상태: 방어선 1~5 구현·실측 검증됨(아래 "현재 방어선"). 나머지는 **알려진 한계** — 우선순위대로 후속 대응.

---

## 현재 방어선 (이미 구현됨)

1. **침대 소속도(bed affinity)** — track별 최근 60초 이력 중 침대존(`BED_X × BED_Y`) 안에 머문 비율. 순간 위치가 아니라 이력으로 "환자다움"을 판정.
2. **walking 게이트** — 실제 보행(속도≥`WALK_SPEED_MIN`, 순이동≥`WALK_DISP_MIN`)일 때만 baseline 반영. 정지/누움 값으로 baseline 오염 방지.
3. **애매하면 보류** — 침대 소속 후보(aff≥`AFFINITY_MIN`=0.25) '사람'이 정확히 1명일 때만 확정. 0명 또는 2명+면 `lock=False`로 보류.
4. **매트리스 코어 존** — 침대존을 매트리스만으로 좁힘(`BED_X=(-0.9,0.4)`). 옆 의자·거기 생기는 고스트를 후보에서 배제. *(실측 튜닝 2026-07-03, #10 완화 A)*
5. **분리 track 병합** — 한 사람이 여러 track으로 쪼개지는(split ghost) 경우, 후보끼리 `MERGE_DIST`(0.7m) 이내면 한 사람으로 병합해 카운트. *(실측 확인 2026-07-03)*

아래는 **이 방어선들로도 아직 못 막는** 케이스들.

> **실측 검증(2026-07-03)**: 붐비는 방(n=4~5)에서 방어선 1~5가 모두 실동작 확인됨 —
> 누운 환자 특정, 누움 보류, 지나가는 사람 순간 보류, 의자 고스트 배제, 침대 위 분리 track 병합 → `cand=1 lock=True` 안정.

## 🔴 미탐지 — 낙상을 못 잡는 경우 (최우선)

### #1 낙상 순간 track이 끊기면 낙상 자체를 놓침
- `height_drop = max(z) - min(z)`는 track이 낙상 내내 유지돼야 계산됨.
- 사람이 쓰러지면 RCS 급감/바닥 밀착으로 **track이 죽는 경우가 많음** → 샘플 끊김 → `n_targets=0` → 보류.
- **결과: 진짜 낙상인데 "아무도 없음"으로 조용히 넘어감.**
- 완화: "존 안에 있던 track이 갑자기 소멸 + 마지막 z 하강" → 낙상 의심 알람.

### #2 천천히 주저앉는 낙상은 임계 미달
- `HEIGHT_DROP_FALL=1.2`m를 한 윈도우(10초)에 넘어야 함.
- 노인성 "스르륵 미끄러짐 / long-lie"는 느려서 미탐지.
- 완화: 절대임계 외 "바닥 근처 z 지속 + 무동작"(주저앉아 못 일어남) 상태 감지.

### #3 여러 명일 때 낙상 감시가 track 1개뿐
- raw(=height_drop)는 `main_tid` 하나만 계산.
- 2명 있을 때 환자가 아닌 쪽(또는 non-main)이 쓰러지면 안 보임.
- 완화: 낙상(z 급강하)만은 **모든 alive track**에 대해 검사.

## 🟠 거짓 알람 — 알람 피로 → 무시 → 위험

### #4 sway / speed_cv 수식이 특정 보행에서 폭발
- `speed_cv = std/mean` → 느린 셔플링(mean 작음)에서 값 폭증 → 거짓 z. *(미해결 — speed_cv sigma 큼, RISK로 유지)*
- `sway`는 시작-끝 직선축 기준 → **방향 전환/제자리 배회(loop) 시 축이 애매해져 왜곡**.
  회전은 sway뿐 아니라 속도↓·stride(FFT cadence) 노이즈까지 **다지표를 동시에 왜곡** → 정상 보행도 거짓 위험 가능.
- 완화 A(직진성 게이트) ✅ **적용됨** — 윈도우 경로 직진성(`순이동/이동거리`)이 `STRAIGHT_MIN`(0.7) 미만이면
  `walking=False`로 처리해 baseline·알람에서 제외. 굽은/왕복 윈도우가 gait를 왜곡하지 못하게 함.
  *(주의: baseline과 실사용 동선의 회전 빈도가 비슷하면 자체 완충됨. mismatch일 때가 위험.)*

### #5 고스트(유리문·금속) 병합 스파이크
- X≈−2.25 반사가 환자 track에 섞이면 speed/sway 순간 폭증 → 거짓 warning.
- 완화: cfg `staticBoundaryBox`로 반사영역 컷 + 물리적으로 불가능한 순간속도 필터.

## 🟡 baseline 오염 / 정체

### #6 평생 누적 baseline → 서서히 나빠지면 "새 정상"이 됨 (삶은 개구리) ⚠️
- `update_baseline`은 sum/sumsq를 **평생 누적**, 감쇠·윈도우 없음. n이 커질수록 새 데이터가 희석됨.
- 환자가 점진적으로 악화되면 그 악화가 천천히 baseline에 흡수돼 **알람이 안 뜸**.
- 낙상위험 "예측"의 핵심(점진적 악화 포착)을 정면으로 놓침.
- 완화: 최근 N일 슬라이딩 윈도우 baseline, 또는 지수감쇠(EWMA).

## 🔵 환자 정체성 구멍 (baseline 오염원)

### #7 `n==1 → 무조건 환자` 가정이 뚫림 ⚠️
- 환자 외출 중 **청소부/간호사 혼자** 방에서 걸으면 → `n=1 lock=True` → 그 사람 보행이 환자 baseline에 들어감.
- 두 명이 붙어 걸으면 tracker가 1개로 **병합** → `n=1` → 역시 lock → 뒤섞인 보행 누적.
- 완화: `n==1`이어도 그 track의 침대 소속 이력이 전무하면 baseline 반영 보류(복귀 초기 딜레마는 튜닝 필요).

### #8 환자가 침대 대신 의자 선호 → 앵커가 틀림
- 환자가 주로 의자에 앉으면 침대 소속도 0 → 다인 상황에서 영영 특정 안 됨.
- 완화: "환자 상주 구역"을 침대∪의자로 확장, 또는 수동 지정.

### #10 침대존이 너무 넓어 "침대 옆 의자"까지 삼킴 🔴 **실측 확인됨 (2026-07-03)**
- 현재 침대존 `X[-1.3,1.1](2.4m) Y[1.0,3.6]`는 매트리스(~0.9m)보다 훨씬 넓음.
  누웠을 때 몸+반사+금속 프레임이 넓게 퍼져 캡처돼서 생긴 과대 존.
- **실측 재현**: 침대 비우고 옆 의자에 2명 착석 →
  둘 다 존 안(`tid=10 x=+0.92`, `tid=17 x=-1.33`)으로 잡혀 `cand=2 lock=False` 지속.
- **파장(가장 흔한 실전 시나리오)**: 면회객이 침대 옆 의자에 앉으면 → 항상 `cand≥2` → 계속 보류.
  게다가 앉은 면회객이 `cand`를 2로 유지 → **환자가 나중에 걸어도 측정 못 함.**
- 완화(권장 조합):
  - **A. 매트리스 타이트 존** ✅ **적용됨** — `BED_X (-1.3,1.1)→(-0.9,0.4)`로 축소. 실측에서 의자 고스트(x=0.97) 배제 확인.
    (정식 재캡처: 환자 혼자 침대 중앙 누움 + p25~p75로 코어 재산정 권장 — 현재값은 1회 실측 기반 잠정치)
  - **B. Z(자세) 게이트** *(미적용)* — 누운 환자 z 낮음(누움 mean −1.09), 앉은 면회객 z 높음(−0.68/−0.87).
    보조 신호로만(환자가 상체 세우면 z 상승 → 놓칠 수 있음).
  - **C. 분리 track 병합** ✅ **적용됨** — 존 안 고스트가 사람과 별도 track이면 병합으로 처리(방어선 5 참조).
- 관련: #5(고스트로 존 오염), #8(앵커 위치).

### #11 스쳐 지나가는 사람도 순간 `cand` 상승 → 짧은 보류 **실측 확인됨 (2026-07-03)**
- aff는 track '자기 이력'의 침대존 비율이라, 침대존을 잠깐 통과하는 사람은 짧은 이력이 전부 존 안 →
  순간 `aff≈1.0`로 후보가 됨 → `cand=2`로 잠깐 `lock=False`.
- 누운 환자엔 무해(어차피 walk=False 보류)하나, **환자 보행 중 누가 침대 옆을 스치면 그 순간 측정 끊김.**
- 완화: "최소 체류시간/최소 샘플 수 이상이어야 침대 후보로 인정"(스쳐가기 배제).
