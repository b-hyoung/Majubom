# 자세 분리(눕/앉/서) — 3m/15° gait 마운트 실측 & 규칙

> 2026-07-05 실측. 목표: **gait에 쓰는 cfg(AOP_bed_2m7_d15.cfg, sensorPosition 3 0 15)를 이탈/자세 파이프라인에 그대로 쓸 수 있나?** → 결론과 그 근거, 그리고 그걸 가능케 한 규칙·방어 정리.

## TL;DR
- **cfg 통합 OK.** gait cfg는 TLV 1010(트랙)+1020(점군)을 그대로 내보내므로 이탈 파이프라인에 기계적으로 그대로 꽂힘.
- **단, 15° 얕은 틸트에서 mmWave 단독 규칙 자세분류는 원래 안 됨.** 아래 방어 5종을 넣어야 "사람 있는 방에서 누운 환자"가 안정적으로 잡힘.
- **핵심 교훈: z_spread(세로 퍼짐)는 이 각도에서 노이즈 범벅이라 못 씀.** 물리적으로 갈리는 축은 `z_cent`(중심높이)와 `z_max`+`n_hi`(높은 점 다수) 두 개뿐.

## 실측값 (혼자, 원시 센서 z, window 1s)
| 자세 | z_max | **z_cent** | n_hi(z>0.5) | 비고 |
|---|---|---|---|---|
| 눕기 | -0.6 (가끔 0.64 튐) | **-1.35** | 0 | z_spread 2.1(노이즈) |
| 앉기 | ~0.5 | **-0.75** | 0~2 | z_spread 0.8 |
| 서기 | 2.0~4.0 (드문드문) | -0.6 | 3~15 (희소) | 점군 폭발 N 1000+ |

- **z_spread 폐기 근거:** 눕기 spread(2.1) > 앉기 spread(0.8) — 물리적으로 뒤집힘(앉으면 더 커야 함). z가 실제 키를 안 담고 멀티패스에 좌우됨.
- **서기 특징:** z_max는 2.0+로 확 뜨지만 그 높은 점이 **소수**(다리·바닥이 점의 90%). 그래서 z_p90은 서기를 놓침 → z_max + n_hi 조합이 정답.

## 분류 규칙 (posture_probe.py `classify`)
```
if z_cent <= -1.05:              → 눕기   # 무게중심 낮음. 위쪽 잡음점 무시(오염 방어)
elif z_max >= 1.2 and n_hi >= 3: → 서기   # 높은 점이 '실제로 여럿' (유령점 1개 배제)
else:                            → 앉기
```
+ **서기 latch(STAND_HOLD=1.5s):** 서기 상체점이 15°에선 드문드문 잡혀 깜빡임 → 조건이 한 번 잡히면 1.5초 유지. 그동안 명백히 누우면(z_cent↓) 즉시 해제.

## 사람 있는 방 방어 스택 (5종)
| # | 방어 | 코드 | 효과 |
|---|---|---|---|
| 1 | z_cent + z_max/n_hi 규칙 | `classify` | z_spread 노이즈 회피, 3자세 분리 |
| 2 | **눕기 우선 판정** | `classify` 순서 | 침대 옆 사람 높은점을 눕기로 덮음 |
| 3 | 서기 latch | `STAND_HOLD` | 드문 상체점 깜빡임 제거 |
| 4 | **침대 ROI 크롭** | `crop_to_roi` | 방 저쪽 사람 수백 점 제거 |
| 5 | min-pts 가드 | `--min-pts 10` | 빈 침대 모서리 잡음 → "비어있음" |

- **크롭 효과 실측:** 방에 사람 여럿 → 프레임당 500~1800점 제거(`crop-N` 로그). 누운 환자 `lie` 판정이 `n_hi=6` 오염에도 안 흔들림.
- **크롭 한계:** 침대 **바로 옆(모서리 여유 margin 안)**에 선 사람은 여전히 샘. → gait의 "걸터앉은 방문객"과 동일한 잔여 리스크. 근본 해결은 점군-트랙 연관(1010↔점)인데 압축 TLV(1020)엔 연관 정보가 없음(향후 과제).

## 침대 ROI (bed_roi.json — 런타임, gitignore)
- 점군 좌표계는 **센서 프레임**(sensorPosition 회전 미적용) — 트랙(1010, 월드 프레임)과 **다름**. 그래서 gait의 BED_X/BED_Y를 그대로 못 씀. ROI는 점군 자신의 프레임에서 잡아야 함.
- **캘리브레이션은 방이 비었을 때** 해야 정확(누운 점 범위로 침대 박스 학습). 사람 있으면 박스가 부풀거나(멀티패스) 뒤틀림 → 실측: 오염 시 y가 6.8m까지 늘어남.
- 최종 ROI는 **실측 침대(215×90cm)**로 수동 설정(중심=깨끗한 calib, 크기=줄자). `z_offset=0` 유지 — 위 임계는 원시 z 기준.

## 재현 방법
```bash
# 1) (방 비었을 때) 침대 캘리브레이션 — 누운 채 10초
python posture_probe.py --data COM6 --calibrate --roi mmWave/bed_roi.json
#    → 필요시 bed_roi.json 을 실측 침대 크기로 수동 보정, z_offset=0

# 2) 자세 판정 (크롭+가드)
python posture_probe.py --data COM6 --roi mmWave/bed_roi.json --crop-margin 0.15 --min-pts 10 --no-log
```

## 이탈 파이프라인과의 관계
- co_log.py/record_seq.py는 자세 라벨을 **ToF에서** 따고 mmWave는 30프레임 점군 시퀀스만 제공 → mmWave가 눕/앉을 스스로 구분할 필요 없음. **위 규칙은 진단·데모용**, 학습셋 라벨은 ToF가 정답.
- 따라서 **cfg 통합 시 이탈 LSTM은 그대로 동작.** 자세 규칙은 "사람이 값 보며 확인"하는 용도로 유효.
