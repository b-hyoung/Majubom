B 촬영 순서 — baseline 먼저

"달라짐"을 보여주려면 비교 기준(baseline)이 먼저 있어야 한다. 데모 전에 아래 3개를 확보.
B1 · CSI

누운 생체 baseline

5분 안정 누움 → HR·호흡 개인 기준선 학습

시연 ①의 기준
B2 · mmWave

정상 보행 baseline

평소 걸음 5~10회 → 속도·stride_cv 기준

시연 ③의 "달라짐" 비교 기준
B3 · ToF

빈 침대 캘리브

사람 없는 침대 → 재실/이탈 임계

시연 ②의 이탈 판정 기준
데모 본 촬영 — 한 스토리로 이어서 (대시보드 화면녹화 동시)
Beat 1
누워 안정 (~10초)
→
대시보드에 CSI HR·호흡 baseline 표출
Beat 2
상체 일으켜 가장자리 → 내려옴 (~10초)
→
ToF(가장자리) + mmWave(앉음) 교차 → "이탈 전조" 알림
Beat 3
걷기: 정상 → 불안정 (~15초)
→
mmWave 보행지표 실시간 · baseline 대비 속도↓·stride_cv↑ = 위험
⚠️ CSI 주의 — 심박·호흡은 누워 가만히 있을 때만 나온다(움직이면 깨짐). 걷는 구간엔 CSI 없음 → CSI 자리는 Beat 1(베이스라인) 뿐.

C 동기화 & 찍기 전 체크

동기화 — 대시보드는 QuickTime 화면녹화, 사람은 카메라 → 편집에서 좌우로. 센서 로그에 타임스탬프가 있어 시각 맞추기 쉬움.
  1. USB 안정화 — 오늘 계속 끊김. 케이블 교체·맥 직결부터 (라이브 데모 전제)
  2. 각 센서 단독 확인 — CSI(박형석)·ToF(조우진)·mmWave(유현기) 각자 그 장면에서 값 나오는지
  3. baseline(B1·B2·B3) 먼저 확보 → 그다음 데모 본 촬영
  4. 대시보드가 이 3종을 실시간 표출하는지 확인 (생체 + 이탈 + 보행 비교)
